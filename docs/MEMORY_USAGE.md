# 运行内存与闲置资源（2026-11-08）

用户报告长时间使用后为 300–400 MB；本轮只读采样确认当前运行的是原目录 Release：WorkingSet64 为 330.3 MiB，PrivateMemorySize64 为 282.3 MiB（私有提交，非任务管理器私有工作集）。没有控制会话数量、目录数据或窗口大小，不能把该数字归因于某个缓存，或作为修复前后可比基线；新机制尚未测量出固定下降值。Dart 自动回收不可达对象，Flutter 也有图片 LRU 和内存压力清理；任务管理器数字包含渲染器、堆的保留容量等，释放对象不保证数字立即下降。

本轮按实际保留点收紧资源：

- 传输历史在内存和磁盘均遵守现有 200 条/30 天规则；活动任务与可恢复 checkpoint 不裁剪。一个批次不再有排队/运行/暂停待恢复任务时，释放其冲突选择。
- 底部目录树按 128 个目录/8192 个子项的目标回收缓存，折叠分支优先；当前路径及祖先的完整列表受保护，单个大目录可能超过目标，不截断目录内容，离开后即可回收。淘汰后展开时重新读取。文件浏览前进/后退历史分别最多 100 项。
- 切走文件页面或所在终端标签 30 秒后，释放只为浏览服务的目录列表、监听和 SFTP 租约，保留连接目标/路径/排序等恢复所需元信息；返回页面重新读取。正在执行文件修改时延后回收；隐藏页面停止动画，挂起状态不显示加载动画。后台传输和外部编辑拥有自己的资源，不因浏览页面隐藏而中断。
- 应用装配层将闲置图片 LRU 限制到 16 MiB/128 项；窗口隐藏、最小化或系统内存压力时清理非活动图片缓存，不清除仍被 Widget 监听的图片，不制造重复解码。
- 终端仍保留用户配置的回滚行数；隐藏的会话不丢缓冲、不主动断开。监控保留最多 60 个采样，隐藏即停止采集。
- 标签栏在不读取会话对象的独立方法中构造，标签 Widget 只保存布局元信息和交互回调；标签 State 自己读取会话、监听状态，并在卸载时移除监听且清空会话引用。框架的语义配置可能延长旧拖动 Widget 和回调的寿命，因此仅拆开交互闭包还不够，Widget 字段及其 builder/listenable 也不能携带 `TerminalSession` 或旧会话集合。文件面板工具栏同样独立构造，关闭和停靠回调不与会话 builder 共用上下文。
- SSH 路由租约由独立对象收束，transport 只保存其释放方法，不保存与认证 UI 共用上下文的局部函数。拨号成功或失败离开时，认证提示包装器断开原 UI；已结束的秘密请求返回空值。rekey 继续经过 `HostTrustService`，已保存且匹配的密钥不依赖 UI；“仅本次”只保留该次拨号批准的精确 endpoint/type/fingerprint 元信息，相同未知密钥可继续校验，其余未知或变化密钥拒绝，不复用旧 UI 放行。
- Fig 静态规格按当前命令分支惰性读取，LRU 最多 32 个文件，输入 UTF-16 成本估算最多 16 MiB（不是解码对象堆的精确限制），原始字符串不留在 AssetBundle 缓存。远程补全只扫描 4096 个名字，缓存 5 秒、16 个目录/16384 个条目，独立 SFTP 通道空闲 10 秒关闭；完整回归覆盖有界和释放行为，大规格解码堆及最终 Release 内存未实测。
- 在线说明翻译只在实际可见行请求，活动请求默认随可见词条并发（最多 32 个，也可配置 1–32）、最多 32 个排队词条、每词条最多 32 等待者；共享请求的各 pane 可分别取消。响应最多 32 KiB、译文最多 2048 字符/8 KiB；当前服务内存缓存最多 4096 条/2 MiB 序列化数据（不是 Dart 堆精确值），磁盘最多五个固定厂商槽，同厂商切换配置替换最近槽，完整原文+语言+服务身份精确匹配。加载与替换写按文件路径串行，旧 provider dispose 的写不能覆盖新身份。非活动浮层不预翻库，网络关闭仍能读缓存；失败冷却，不保留错误结果或秘密。

不加定时强制 GC、不调用 Windows 工作集裁剪来制造短暂低读数。验证以有界状态、关闭/闲置释放和恢复行为测试为主；没有新的运行测量时，只报告机制与已验证行为。
