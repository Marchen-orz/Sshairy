# 品牌图标（2026-11-06）

用户要求重新通过 GPT 生图 skill 生成 logo，替换手绘终端机器人。本文先记录本轮设计约束；具体生成结果与检查情况见 ROADMAP。

- 延续产品含义：轻量 SSH、终端连接；略带可爱，适合日常开发工具。以清楚轮廓和命令提示符表达，不堆叠锁、服务器、电路、AI 星芒等装饰。
- 本轮方向是轻盈的冰青色小精灵：柔和的非对称轮廓，`>` 与短光标组成简练表情。减少旧版的机壳、线缆、脚、腮红和高光；避免变成玩具机器人。
- GPT Image 生成独立原创的栅格母版。使用本机 `imagegen` 与 `imagegen-config-fallback` skill；不借用 Netcatty 或其他产品素材。
- 请求 1024×1024 PNG。实际接口返回一张 1254×1254 RGB 图（虽然请求了两个候选），保留在 `output/imagegen/sshairy-logo-1.png`；不将请求尺寸或数量冒充输出事实。透明母版规范化为 1024×1024，路径 `assets/brand/icon-source.png`。生成图不声称是 SVG，不用外链 SVG 包装 PNG 冒充矢量源。
- 以实际输出为准，检查明暗背景、边缘、16/24/32/48/64/128/256 px 的辨识度。透明版由纯色背景边缘分离导出，并检查边缘残色；保留原始生成图。
- 应用内 PNG、Windows ICO 与 macOS 图标从同一选定母版导出。平台图标导出不等同于平台运行验收。
- 当前任务也复核最初架构、UI、数据保护与验收规范。已声明未完成的功能与违反硬约束的问题分别记录，不能因单元测试通过就宣称设计全部落实。
