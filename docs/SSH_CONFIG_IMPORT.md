# SSH config 导入（M3）

这是受限的配置读取与主机元信息导入，不调用 ssh、不执行命令、不读私钥内容，也不修改源文件。实际验证结果登记 ROADMAP。

## 读取边界

用户选择 config；Include 仅能读取所选文件目录树下的相对路径，包含基础 `*`/`?` 文件名模式，不支持绝对路径、`~`、`..`、环境替换和 `**`。路径规范化后再检查真实路径，符号链接不得跳出目录树。最多 4 层 Include、32 次文件读取、总计 1 MiB；循环、缺失、超限和越界均报告。Include 在原位置展开，之后的首值判断保持文本顺序。任何未完整读取的 Include 都令本次预览不可提交，避免丢失路由规则后误导入成直连。

## 解析范围

- 关键字不区分大小写，接受空格或 `=` 分隔、引号及引号外注释；非法行给出文件与行号。
- 仅显式 Host 别名产生草稿。含 `*`、`?`、否定的 Host 模式只提供匹配默认值，不生成伪主机；简单模式按别名匹配。每项取第一个匹配值。
- 支持 HostName、User、Port、IdentityFile、ProxyJump。缺省 HostName 使用别名、Port 为 22、User 为本机用户名。IdentityFile 只保存可解析的路径引用；`~` 仅展开当前用户 home，支持 `%h`（解析后的地址）、`%n`（原别名）、`%r`（用户名）、`%d`（home）及 `%%`，其他变量报告并阻止该草稿。多个 IdentityFile 只支持第一项，额外项报告。
- Match 区块直到下个 Host 都不应用并报告；Match 的判断从不执行。ProxyCommand 不执行；有效非 `none` 值阻止对应草稿导入。其他未支持关键字只报告关键字与位置，不展示原始值，避免把内嵌凭据复制进错误信息。
- HostName/User/Port 或路径变量无效、无法解析的跳板、跳板循环/超长均阻止对应草稿；不会静默删掉跳板而导入成直连。

## 预览与提交

预览展示有效主机、已有端点、被阻止项和未支持报告。已有相同地址（忽略大小写）/端口/用户名的主机不覆盖且默认不选；必要的新跳板随目标一起提交。ProxyJump 可以引用配置别名或唯一匹配的已保存主机，支持 `user@host:port` 与括号 IPv6；不修改已保存跳板的上游。多跳按从入口到目标顺序构建，已有跳板若需不同上游则复制成新元信息草稿，引用链最多 8 个主机。

用户确认后重新核对预览对应的 hosts revision，通过 HostsNotifier 的单写队列校验整个新增集合及引用，并一次写盘后发布；配置期间变化则要求重新预览。文件路径引用不会自动把密钥导入系统安全存储；之后连接时仍走既有凭据与 HostTrustService 流程。关闭对话框不保存草稿。入口与其他来源见 `HOST_IMPORT.md`。
