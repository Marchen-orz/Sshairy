# 工作区导航与面板

2026-11-07 第二版，取代第一版的 224 px 导航列和终端左侧主机树。布局总则见 UI §1；监控数据见 MODULES §8。

- 图标栏（`design/icon_rail.dart`）48 px 常驻全部页面。页面项切换主机库和 SFTP；浮层项打开密钥、转发、片段、信任记录；底部是命令面板和设置。同一时刻只开一个浮层，再点同一项关闭。
- 浮层（`design/side_drawer.dart` 的 `showFlyout`）是一个 PopupRoute：贴在图标栏右侧，Esc 或点外部关闭，关闭后焦点回到打开前的位置。命令面板的“设置”能力也打开同一个浮层。
- 快速连接：顶栏 `+` 在按钮下方弹出主机树（搜索、分组展开、连接状态），选中主机调用 `Workspace.openHost` 后关闭；Ctrl+Shift+N 仍切到主机库。主机树自身不拨号，连接状态由工作区传入，不让 hosts 依赖 terminal。
- 监控面板在终端标签内、图标栏右侧，240 px；窗口宽度不足 1200 px 时不显示（开关保留，宽度恢复后再出现）。数据跟随标签里获得焦点的 pane；pane 未连接时显示该状态，不自己拨号。
- 文件面板（`design/dock_panel.dart`）按设置 `filesDock` 停靠在左、右或下。左右停靠时宽度 300–560，终端不足 480 时改为同侧覆盖层（遮罩、Esc、关闭按钮）；下方停靠时高度 160 到可用高度的 60%。拖动 8 px 命中区时只显示导线，松开后提交；双击恢复默认；分隔条支持键盘方向键和语义增减。
- 浮层和右侧编辑面板从顶栏下方开始，不遮住标签行和窗口按钮。顶栏的拖动区放在标签与按钮之后（Stack 底层），不包住它们：拖动区的双击识别会让包在里面的按钮每次点击都等双击超时。
- 面板开关、宽高属于窗口内瞬时布局，不写配置、不注册 Capability；`showMonitor`、`filesDock` 是持久化设置，经 settings.patch 可改。
- 所有新增文案走 zh/en i18n，尺寸放入 design tokens。

自动验证覆盖图标栏切页、浮层开关与 Esc、快速连接、停靠位置切换与限宽、监控解析。2026-11-07 在作者自己的调试实例里看到监控面板连作者服务器实时显示（CPU、内存、交换、网络、磁盘、运行时长），GPU 卡片没有测试环境；真实窗口的拖动、DPI、输入法需实机验收，不由组件测试推定通过。
