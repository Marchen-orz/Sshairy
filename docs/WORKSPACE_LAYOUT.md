# 工作区导航与面板

2026-11-07 第二版，取代第一版的 224 px 导航列和终端左侧主机树。布局总则见 UI §1；监控数据见 MODULES §8。

- 导航（`design/icon_rail.dart`）常驻全部页面，收起 48 px，展开默认 200 px、拖动右侧分隔线在 176–320 px 间调整（导线、松开提交、双击恢复、键盘与语义增减）；展开显示完整菜单名和关于区同款横版 Logo，底部按钮切换。展开状态与宽度像文件面板停靠位置一样记入设置（`navigationExpanded`、`navigationWidth`），下次启动恢复；拖动只在松开时写一次。浮层避让当前导航宽度，命令面板中的设置入口也使用相同避让。顶栏 44 px、内容 36 px、上下各留 4 px；收起时 IP 图形居中，展开 Logo 头部高 76 px。页面项切换主机库和 SFTP；浮层项打开密钥、代理、转发、片段、主机密钥、日志；底部是命令面板和设置。同一时刻只开一个浮层，再点同一项关闭。
- 浮层（`design/side_drawer.dart` 的 `showFlyout`）是一个 PopupRoute：贴在图标栏右侧，Esc 或点外部关闭，关闭后焦点回到打开前的位置。命令面板的“设置”能力也打开同一个浮层。
- 快速连接：顶栏 `+` 在按钮下方弹出主机树（搜索、分组展开、连接状态），选中主机调用 `Workspace.openHost` 后关闭；Ctrl+Shift+N 仍切到主机库。主机树自身不拨号，连接状态由工作区传入，不让 hosts 依赖 terminal。
- 主机库分组筛选胶囊在名称右侧显示主机数量，包括固定的“全部主机”和数量为 0 的空组；统计当前完整主机库，不随搜索缩小，父组包含全部后代组，与点击该组的筛选范围一致。数量随主机新建、移动和删除更新，沿用胶囊文字与间距，不增加标题或说明。
- 分组拖动松手后，分组条同步保持刚放下的同级顺序，再等待既有 typed 用例提交；本地预览仅影响条带顺序，不提前发布主机库、改归属或生成新 Capability。保存完成接上已提交顺序，不闪回旧位置；保存失败或异常恢复当前已提交顺序并显示既有保存错误。保存期间不再启动第二次排序，单击筛选和右键菜单保持可用；若其他编辑先更新主机库，撤销旧快照的预览，后续完成不能覆盖较新的顺序。
- 监控面板（`design/sidebar_frame.dart`）在终端标签内、图标栏右侧，默认 240 px；窗口宽度不足 1200 px 时不显示（开关保留，宽度恢复后再出现）。拖动右侧分隔线在 240–400 px 间调整，与导航、文件面板一致：拖动只画导线、松开提交，双击恢复默认，方向键与语义增减。右侧页面（终端与文件面板）至少留 480 px，上限随可用宽度收缩；窗口变窄时只缩小显示，不改写已存的宽度，变宽后恢复。调整宽度、窗口缩到 1200 px 以下再放大，都不重建终端和文件面板；调整宽度也不重建监控面板，采样与租约不受影响。宽度记入设置 `monitorWidth`，拖动只在松开时写一次。数据跟随标签里获得焦点的 pane；pane 未连接时显示该状态，不自己拨号。
- 文件面板（`design/dock_panel.dart`）按设置 `showFiles` 开关、按 `filesDock` 停靠在左、右或下。左右停靠时宽度 300–560，终端不足 480 时改为同侧覆盖层（遮罩、Esc、关闭按钮）；下方停靠时高度 160 到可用高度的 60%，左边是目录树、右边是列表（MODULES §4）。文件面板只保留一层路径操作栏，停靠位置和关闭按钮放在该栏最右侧，不再单独占用上方一行；窄侧栏把前进/后退放入更多菜单，给路径和操作留出空间。目录树的选中背景与点击反馈限制在各自列表行内，滚动时随内容裁剪，不能覆盖工具栏。拖动 8 px 命中区时只显示导线，松开后提交；双击恢复默认；分隔条支持键盘方向键和语义增减。
- 进程窗口是居中的大对话框（不是侧边抽屉），关闭后监控面板继续按原间隔刷新。
- 顶栏标签宽 80–200 px 随标题伸缩，关闭按钮贴标签右缘，常见的短标题不在关闭按钮后留空。顶栏右侧的监控、文件、分屏、传输按钮之间留 2 px，相邻两个都处于选中态时仍是两块独立的圆角底色。
- 浮层和右侧编辑面板从顶栏下方开始，不遮住标签行和窗口按钮。顶栏的拖动区放在标签与按钮之后（Stack 底层），不包住它们：拖动区的双击识别会让包在里面的按钮每次点击都等双击超时。
- 监控与文件面板的开关是全局持久化设置 `showMonitor`（默认开）和 `showFiles`（默认关），与停靠位置一样记入设置，所有终端标签共用，不按主机分别记。顶栏按钮、文件面板的关闭按钮、覆盖层的 Esc 与遮罩都写同一个设置；新开、复制和下次启动恢复的标签按最新开关显示。写入不动已存的宽度与停靠位置。文件面板的宽高仍是窗口内瞬时布局，不写配置；开关不另注册 Capability，经 settings.patch 修改。
- 文件浏览器打开时会申请连接，因此文件面板只在该标签的终端已连接（`SessionStatus.connected`）时挂载，以复用已有连接。恢复后未连接、连接中、认证或主机密钥被拒绝而失败、连接断开的标签都不显示面板，开关保持原值；终端连上或重试成功后面板出现。监控面板本来就不拨号。
- `showMonitor`、`showFiles`、`monitorWidth`、`filesDock`、`navigationExpanded`、`navigationWidth` 是持久化设置，经 settings.patch 可改。
- 所有新增文案走 zh/en i18n，尺寸放入 design tokens。

自动验证覆盖图标栏切页、浮层开关与 Esc、快速连接、停靠位置切换与限宽、监控解析。2026-11-07 在作者自己的调试实例里看到监控面板连作者服务器实时显示（CPU、内存、交换、网络、磁盘、运行时长），GPU 卡片没有测试环境；真实窗口的拖动、DPI、输入法需实机验收，不由组件测试推定通过。
