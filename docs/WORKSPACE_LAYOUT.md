# 工作区导航与工具面板收尾

2026-11-07。落实 UI §1、§4 的既定布局；不增加新的业务状态或 AI 入口。

- 主机库左侧使用 224 px 导航，提供现有主机、密钥、转发、片段和信任记录入口；窄于 1200 px 时收为 56 px 图标导航。未实现的连接记录不显示占位入口。密钥、转发和片段沿用现有抽屉；信任记录复用现有管理组件。
- 终端左侧是按分组路径组织的主机树，支持搜索、展开/收起和连接。连接状态由工作区传入，不让 hosts 依赖 terminal。主机树可整体隐藏；窄窗口默认隐藏，按钮可打开覆盖层，关闭后返回终端。
- 工具面板初始 360 px、范围 300–560 px。拖动 8 px 命中区时只显示导线，松开后提交宽度，避免每帧重排终端；双击恢复 360 px。分隔条支持键盘左右调节和语义增减。
- 当工具面板会让终端小于 480 px 时使用右侧覆盖层；保持终端原宽。覆盖层有关闭按钮、遮罩与 Esc，点击遮罩关闭，不关闭 shell 或传输。侧栏和覆盖层切换复用同一个面板状态。
- 宽度和展开状态属于窗口内瞬时布局，不写配置，不注册 JSON Capability。主机连接仍调用 Workspace.openHost；主机树自身不拨号。
- 顶栏、主机库工具栏在窄空间减少次要动作；保留现有新建、导入、搜索和设置入口。所有新增文案走 zh/en i18n，尺寸放入 design tokens。

自动验证覆盖主机树搜索/分组、窄/宽布局切换、工具面板限宽/拖动/Esc 与原工作区回归。真实 Windows 拖动、DPI、输入法和 SFTP 尚需实机验收，不由组件测试推定通过。
