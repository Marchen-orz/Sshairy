## M4 SSH 专用 AI

在既有 typed 用例、API 边界、租约/信任和窄凭据端口上实现 Airy，由模型自行选择步骤。模型只获得四项逐项审核的能力：范围内主机别名列表、固定 Linux 诊断、按本 turn 权限模式控制的独立 exec、已允许发送的输出投影；旧 Capability 仍默认不向 agent 开放。用户可选观察/确认/自动，默认确认；观察只开放固定只读诊断，确认逐条批准命令，自动免逐条批准，所有模式保留主机信任、身份重验、持久 intent 和单独输出发送选择。发送时冻结权限模式与聚焦 SSH 主机，无聚焦时由模型查询本次主机快照并根据对话选择，未明确则追问；代码限制已知 ID、先列表和拨号前锁定单机。当前为单服务配置，可分别选择默认 Airy、行内与补全模型，聊天底部切换本窗口当前模型并显示上下文估算比例。会话历史有界本地保存；明确继续且目的地/实际主机/完整路由绑定匹配后，仅以有限普通数据续传，每 turn 使用新的 owner、审批与协议上下文，不恢复权限模式，不自动重试。AI 总开关默认关闭，行内生成和 AI 补全经独立无工具通道、默认开启，各自高级设置仅过滤可用主机，自动使用有界同会话命令历史；实现不代表三入口实网验收完成。
