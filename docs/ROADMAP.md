## M4 SSH 专用 AI

首批在既有 typed 用例、API 边界、租约/信任和窄凭据端口上实现 Agent 架构。模型只获得四项逐项审核的能力：授权主机别名列表、固定 Linux 诊断、逐次获批的独立 exec、已允许发送的输出投影；旧 Capability 仍默认不向 agent 开放。当前为单 profile、单机选择 UI、每次发送新建协议上下文，不自动重试或跨 turn 续接。

- [x] AI v0.5 实施契约：三入口与完整目标保留，明确首批架构交付及后续边界，见 AI §13。
- [x] 首批模型接入：独立配置/窄凭据、Anthropic Messages 与 OpenAI-compatible Chat Completions、增量 SSE/取消、有界请求和侧栏文本解释。
- [x] 首批确定性授权：schema/能力目录、scope/revision/deadline、精确批准对象、实际连接身份绑定和执行前重验；取消/改配置/改 Key/连接身份变化使旧授权失效。
- [x] 首批执行与数据：真实双流独立 exec、持久 intent/未知恢复、固定 system/storage 投影、有界 OutputStore、访问和发送权分离、可编辑发送预览、应用级 Stop/退出接线；终端上下文/快照/草稿窄端口已建立。
- [ ] 首批实网验收：作者选定模型/真实 Key、Ubuntu 上 Agent 诊断/批准/取消与共享连接，以及 AI 开关同条件 Release 资源对照；本轮仅自动替身与本地协议服务器验证。
