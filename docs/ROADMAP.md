## M4 SSH 专用 AI

模块化单体、typed 用例、API 边界、租约/信任、窄凭据端口和配置 revision 可继续复用；当前 Capability 默认不向 agent 开放。接模型前必须完成确定性授权与安全投影，不能仅开启 `agentExposed`。

- [x] AI v0.4 详细设计：三入口职责/工具/上下文/触发分开，明确完整 SSH Agent 目标及分期；保留固定版本竞品证据与协议参考，仅设计未实现。
- [ ] M4a-1：共用模型配置/窄凭据、两类协议/SSE、取消/调度、侧栏解释与附件；三入口独立配置/发送授权（A-01/13）。
- [ ] M4a-2：行内自然语言本地识别、pane AI 图标/组合键、原位 loading、结构化生成/可编辑预览、空行接受与显式本地输入层（A-10/11）。
- [ ] M4a-3：AI 补全的意图门槛/abstain、停顿/限频、近期同会话历史投影、纯后缀顶置与选中身份保留（A-12/13）。
- [ ] M4b：AgentRuntime 单 turn/唯一 Stop；dispatcher scope/revision/deadline、绑定审批、执行前重验、schema/工具 allowlist、安全 DTO、访问与发送权分离（A-02/03）。
- [ ] M4b：流式 CommandExecutor、受限终端快照、独立固定诊断、Evidence 引用与 OutputStore；先 acquire 再 exec，不经自动重拨回调重放。
- [ ] M4b：operationId/持久 intent、未知结果/重试与审计；重启不自动恢复副作用（A-04）。
- [ ] M4c：普通设置/纯布局的冲突安全撤销、会话真实终态、同模板跨机差异、变更前后验证、脱敏历史与用户导出（A-05/06/07）。
- [ ] M4c：AI 禁用后的 SSH 独立性，三入口预算/长输出回收与同条件 Release 性能（A-08/13）；现有内存高峰仍独立保留。
- [ ] M4d：完整 Agent 的主机/组/会话管理、远程文件写入/操作、用户选定本地资源的传输、转发与受管长 job（A-14）。
- [ ] M4d：受约束诊断流程保存/重跑，类型化参数/断言、版本变化重新授权（A-09）。
