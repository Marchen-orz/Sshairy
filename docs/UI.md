# 桌面界面与交互规范

v0.3 · 2026-11-07。借鉴 Netcatty 的浏览器式标签、彩色主机标识、主机库和终端工作区；不复制 logo、品牌素材或繁多工具栏。以下尺寸为 sshairy 设计值，单位均为 Flutter logical px，非截图物理像素。视觉效果以实际使用为准，不因“用了 Flutter”就宣称更流畅。

## 1. 界面骨架

2026-11-07 起（作者要求更紧凑、圆润，交互接近但优于 FinalShell）：左侧是常驻的窄图标栏，二级内容以浮层弹出，不再占一整列；终端标签左侧可展开服务器监控，文件面板可停靠在左、右或下方。

终端工作区：

```text
┌──┬─────────────────────────────────────────────────────────────┐
│◉ │ [web-1 ●] [db · 2] [+]                 [▤][▭][⧉][⇅]  ─ □ ✕ │
├──┼───────────┬─────────────────────────────┬───────────────────┤
│▣ │ web-1     │ terminal pane               │ 文件（停靠右）     │
│⇅ │ CPU  ▂▃▅  │                             │ /home/user        │
│──│ 内存 ███░ │                             │ ▸ src             │
│⚿ │ 交换 █░░░ ├─────────────────────────────┤   README.md       │
│⇄ │ GPU  ██░░ │ terminal pane               │                   │
│{}│ ↓ 1.2M ↑  │                             │                   │
│✓ │ / ████░   │                             │                   │
│⌘ │ /data ██░ │                             │                   │
│⚙ │           │                             │                   │
└──┴───────────┴─────────────────────────────┴───────────────────┘
```

- 导航支持收起/展开：收起宽 48，仅图标；展开默认 200、可拖动右侧分隔线在 176–320 间调整（拖动只画导线、松开提交，双击恢复默认，方向键与语义增减），显示完整菜单名，顶部使用与关于区相同的完整横版 Logo（宽度随导航，最大 208，头部高 76）。展开状态与宽度是持久化设置（`navigationExpanded`、`navigationWidth`），拖动只在松开时写一次。底部有展开/收起按钮，保留键盘与语义操作。上方是页面（主机库、SFTP），分隔线后是浮层（密钥、代理、转发、片段、主机密钥、日志），底部是命令面板与设置。当前页面用主题主色以 18% 叠加在导航底色上的圆角背景标出，选中文字单独校正至背景上至少 4.5:1 对比度；终端标签激活时两个页面都不高亮。
- 浮层从图标栏右侧弹出：宽 400（设置 440），从顶栏下方 8 到窗口底部 8，圆角 14，带阴影；点外部或 Esc 关闭，焦点回到原处。浮层里再打开的编辑器（转发规则、片段、身份等）以右侧浮动面板叠在上面，不另开页面。
- 顶栏总高 44，内容高 36，上下各留 4；品牌图标 28 居中，避免紧贴上沿。最大化时原生客户区排除不可见缩放边框，不能把内容的上几像素裁到工作区外。顶栏包含品牌图标、会话标签、`+`、当前标签的面板开关（监控、文件、分屏、传输）和窗口按钮。`+` 弹出快速连接浮层（搜索 + 分组主机树），选中即连；原先终端左侧常驻的主机树并入这里。标签 28 高、80–200 宽；多余标签横向滚动，不缩成无法点击的碎片。
- 监控面板默认 240 宽，可拖动右侧分隔线在 240–400 间调整（拖动只画导线、松开提交，双击恢复默认，方向键与语义增减；终端至少保留 480，窗口变窄时只缩小显示），宽度是持久化设置 `monitorWidth`。只在终端标签里出现，显示该标签当前 pane 所连服务器的信息（MODULES §8）：IP、运行时长、负载，CPU/内存/交换三个环形图，前 5 个进程（点击打开进程窗口），网络与网卡选择，磁盘表；有 NVIDIA 或 AMD 显卡时可切到 GPU 页。刷新间隔在面板顶部选。开关是持久化设置 `showMonitor`。
- 文件面板停靠位置（左、右、下）是持久化设置 `filesDock`，在面板头部的菜单里切换。左右停靠默认 360、范围 300–560，终端至少保留 480，不够时变为覆盖层；下方停靠默认 260、范围 160 到可用高度的 60%。拖动分隔条只画导线，松开后提交，避免每帧重排终端。尺寸属于窗口内瞬时布局，不写配置。
- Windows 使用无系统顶栏的自绘窗口（ADR-12），窗口按钮在右，与标签行融合；不在 Win 画假的红黄绿按钮。保留原生拖动、双击最大化、边缘缩放、Snap、系统菜单与屏幕阅读器语义。关闭按钮和系统关闭共用 ShutdownCoordinator，默认退出前确认（设置 `confirmQuit`）；有进行中的传输、未上传的编辑或活动隧道时，关掉该设置也会提示。确认后窗口立即隐藏，后台清理在窗口消失后完成。其他平台目前保留原生外框，未验证的行为在 ROADMAP 记录。
- 主区域使用层次清楚的 surface 和细边框，浅阴影；不全屏毛玻璃、不做大面积动态渐变。
- 编辑抽屉（右侧浮动面板）默认 400，从顶栏下方 8 开始，下右各留 8，圆角 14；不遮住窗口按钮。
- 最小支持窗口 960×640；该尺寸隐藏监控面板、文件面板变覆盖层、工具栏溢出。常用窗口大小不溢出。

M4 右侧增加 AI 页签，沿用文件面板的停靠约束。未实现模块不显示空按钮、不可用入口或假数据。设置在窗口内打开，不额外常驻一个 Flutter engine。

## 2. 设计 tokens

使用 ThemeExtension/不可变 token 对象，按语义命名，不在业务 Widget 写散落色值。品牌图标颜色与 ANSI 色是明确例外，走单独映射。

2026-11-07 起整套配色采用作者的 `Sshairy-Brand-Asset-Pack/`，替换此前四个强调色预设。六套主题复用相同布局和组件，每套都有独立浅色/深色；详细素材约束见 BRAND。

| 主题（持久化值） | 浅色品牌主色 | 深色品牌主色 | 深色背景 |
|---|---|---|---|
| 冰蓝薄荷（blue，默认） | #2E6EF7 | #5AB6FF | #0B1420 |
| 薄荷绿（green） | #168A6A | #54D6AE | #0C1916 |
| 紫罗兰（violet） | #7353C7 | #B79AFF | #14111E |
| 日落橙（orange） | #D86B30 | #FFAE70 | #1D1510 |
| 深海蓝（deepSea） | #19559E | #71AAE0 | #0A131F |
| 樱花粉（pink） | #C4548E | #F4A1CB | #1D121A |

深色 background/sidebar/surface/raised、边框、文字、选择色、状态色与终端 ANSI 使用各套 `dark/theme-dark.json` 的精确 token。浅色包只提供八个品牌色：background 使用 surface，面板使用 white，侧栏从 surface 与 mist 混合；文字使用 ink，边框和次级文字从 ink 与白色派生。品牌色用于图形与预览，交互主色必要时沿同一色调加深，保证小字对比度。冰蓝薄荷浅色的界面强调色在原始 #2E6EF7 上微调为 #2C71E8（色相向天蓝偏 3°、饱和度略降，更柔和地配合角色的天蓝与薄荷色），填充按钮直接使用该色配白字（对比度 ≥4.5），小字链接/焦点按背景再校正。主色本身能承载 4.5:1 文字时填充按钮用主色，否则用校正后的同色调深色。素材原图的品牌色保持原样。错误、成功、警告保留独立红/绿/黄色语义。

设置以 3×2 的同结构预览卡呈现六套主题，预览跟随当前明暗。切换后背景、组件、终端和应用内 Logo 一起更新，原有明暗/跟随系统设置不变。正文目标至少 4.5:1，焦点和重要控件边界至少 3:1；不把素材包的对比度报告当作整个应用的验收结论。

终端使用当前主题的 terminal-bg/terminal-fg/terminal-cursor 与选择色；浅色使用白底和 ink，ANSI white 使用可见灰色。搜索高亮同时定义前景，不能让浅色字落在浅色高亮底上。

品牌图形使用对应主题与明暗的素材；图标栏用紧凑角色，设置关于区显示提供的横版 Logo。装饰图形一律半透明、不可交互、不进入语义树：主机库空状态用角色动作（约 70% 不透明，暗色 72%）配淡云、风线和星光；主机较少、列表下方留有整块空白时，右下角放一幅很淡的角色动作（浅色 12%、深色 9%），列表会碰到它时不显示。这两处的动作从默认、开心、成功、疾速、睡在云上中选：每次主机库重新显示时随机换一个，停留在主机库时每 45 秒以 1.2 秒淡入淡出换成另一个；主机库不可见时不计时，系统要求减少动态效果时只在显示时随机、不定时切换。思考（AI）动作留给 AI 功能。浮层的空列表用小幅动作配“无”：密钥用安全盾牌，片段用专注编码，端口转发用已连接，传输浮层用 SFTP 传输（约 55%，暗色 60%：半透明白色角色在深色底上偏灰，需略高）。实际终端、文件列表、监控数据区和认证/安全确认不放内置角色装饰。用户可在设置中分别选择软件界面与终端背景图，单独调图片透明度并恢复默认；只处理背景层，文字、光标、选择和弹层不跟着变透明。导入、容量和显示规则见 BACKGROUND_IMAGES。平台静态安装图标使用官方默认冰蓝薄荷素材；Windows 运行中的窗口/任务栏图标随六套主题及有效明暗模式即时切换，跟随系统时也更新。程序文件和固定快捷方式的静态图标不由运行时换肤改写。应用内图形随主题切换。导入与缩小由 `tool/import_brand.py` 完成，不修改原始包。

- 间距：4/8/12/16/24/32；圆角：8 控件、12 卡片、14 面板/浮层/对话框，开关与分段控件用胶囊形；不为每处单独发明半径。
- 界面缩放：外观设置新增 `uiScale`（80%–150%，默认 100%，立即生效并持久化），整体调整按钮、图标、间距、面板、文字和终端显示大小，字号设置仍可独立调整基准字号。通过根布局的虚拟视口统一缩放，浮层/菜单的锚点换算到 Navigator 坐标，Windows 最大化命中区使用变换后的真实屏幕尺寸；切换时保留页面、对话框和会话。高缩放下按可用虚拟空间应用窄窗口布局。
- 字体：界面字体可选系统已安装字体，默认 Windows 用 Segoe UI 配 Microsoft YaHei UI 显示中文（显式 fallback，不让系统挑到日文字形）；界面字号默认 13，范围 11–18，次级 = 字号 − 1（不低于 11），标题 = 字号 + 3。终端字体默认 Cascadia Mono，中文回落 Microsoft YaHei UI；终端字号默认 14，范围 8–32。字体列表来自系统枚举，终端只列等宽字体。界面里的等宽文字（指纹、路径、权限）用终端字体。包体不附带字体。
- 控件高度：按钮/输入 32，图标按钮 28，列表行 34，主机卡片 64，树行 26。图标默认 16，工具栏 16–18，窗口按钮 36×28 圆角（控件圆角）悬浮底色，按钮间距 2，关闭按钮右侧留 8；关闭悬浮为危险色底。点击区可大于 glyph。
- 主机头像卡片 32×32，行内 24；优先通用服务器/数据库 glyph。发行版图标使用单独审核来源的素材，未知系统用通用图标，不凭 hostname 猜发行版。
- 动画：反馈 120ms，普通 180ms，面板 220ms；统一 ease-out。减少动画时关闭位移/缩放/闪烁，保留即时状态反馈。

## 3. 主机库交互

主机卡：左头像；右名称、user@host；状态点与 pin。hover、键盘焦点或选中时显示“连接/更多”，选中背景与焦点分开。单击替换选择，Ctrl/Cmd 单击切换多选，Shift 按当前筛选/排序后的可见顺序从锚点范围选择，Ctrl/Cmd+Shift 合并范围；Space 切换当前项，Ctrl/Cmd+A 选择可见项，Esc 清空。搜索/分组变化时清除不可见选择，切换网格/列表保留。普通双击或 Enter 连接；带多选修饰键的点击不连接，双击用 `design/double_click.dart` 判断，保持单击立即响应。

主机项的“更多”和右键针对已选项时保留批选，针对未选项时仅选它；单选保留编辑/复制/置顶/移动/删除，多选只显示可批量执行的“移动到分组”和“删除”，不混入单台动作。主页“更多”也可移动或删除当前选中集合。移动目标可为已有分组或“不分组”；删除统一确认数量，取消不改动。两者经 typed 批量用例单次写入，过期 revision、缺失目标或保存失败不发布部分成功。移动保留每台主机覆盖与其他元信息，继承项随新组解析；删除仅删除所选主机，若仍被未选主机、分组或全局默认值作跳板引用则整批拒绝，同批删除的主机间引用不阻挡。保存后清理各自的主机凭据，不删除共享私钥；凭据清理失败如实提示，不能把已提交的删除冒充回滚。

搜索即时本地过滤；无结果显示短状态与“新建/快速连接”动作，不放营销说明。空库 pose 下显示“暂无主机”和一行新建/导入指引；空分组显示对应短状态，不误称整个库为空。现有新建主机和导入入口保留。分组筛选胶囊把 16 px 文件夹图标与文本放在同一紧凑行，间距 4 px、垂直居中，不额外保留 avatar 槽。导入是居中对话框：先选来源（从文件，或各软件方块显示找到的会话数），再预览勾选并选目标分组；首次启动且库为空时自动打开一次，可跳过（`HOST_IMPORT.md`）。长名称省略并 tooltip，实际地址在连接/审批时完整显示。

分组筛选标识支持同级拖动排序：落在目标左/右半分别放到它之前/之后，拖动项半透明、有效目标显示主题色轮廓，松开后单次保存。不可把“全部主机”或另一父级当排序目标，不改变归属与继承；同级顺序随主机库保存，重启恢复。拖入分组改变归属与主机拖拽排序尚未实现，不把它们与分组标识排序混称完成。表单采用 label+input；错误邻近字段，底部只有明确保存/取消。高级设置折叠，不让基础连接表单一开始显示所有参数。

详情顺序：名称/地址/端口 → 用户/身份认证 → 分组/标签 → 路由（M3）→ 连接高级参数 → 终端覆盖。继承项可查看来源和改为独立值；“继承”和“禁用”必须可区分。

桌面纵向内容实际溢出时，在末端预留 16 px 滚动条槽（6 px 滑块加至少 10 px 间隔）；没有产生滚动的菜单和区域使用完整宽度，不留空槽。滑块淡出不影响已经溢出的视口留白。槽位属于视口外部布局，固定表头和网格通过同一作用域读取实际留白；内容减少或滚动视口移除时同步恢复。设置、列表、浮层、编辑表单及监控页共用，边界防抖避免宽度变化反复切换。横向滚动和终端字符视口保持原尺寸；窄导航沿用按钮两侧留白，使用 4 px 滑块以保留按钮居中和间距。

## 4. 终端和工具面板

- 工具条保留主机、连接状态、文件、分屏和更多；搜索、清屏、日志、复制会话放菜单/命令面板，不默认摆 9 个难辨图标。
- 顶栏标签右键提供关闭左侧、关闭右侧、关闭其他标签，以点中的标签为基准并保留它；没有对应目标时置灰。关闭目标中的全部分屏并复用既有 shell 释放流程；原活动标签被关闭时激活基准标签，否则不跳页。
- 监控与文件面板开关作为全局布局设置保存，在新开或恢复的服务器标签生效；监控宽度和文件停靠位置沿用既有持久化设置，文件宽高仍为窗口内布局。从工具条和文件栏关闭入口修改同一开关。恢复布局不自动连接服务器。
- 补全候选先列会话历史，再列规格、路径、片段等来源；总量上限与可见行数分开，列表可滚动。紧凑浮层跟随实际光标右边缘，支持上下避让、pane 边界、滚动和缩放；命令与左对齐解释相邻，解释省略、悬浮显示完整内容。出现即选中首项，上下移动；左右只有存在下一级/上一级时浏览，否则交 shell 移动光标。Tab 补入后缀并在完整词后补空格，目录和连写选项值保持开放；目录浏览只改候选状态，Enter 仍提交实际草稿。Esc 关闭，Ctrl/Cmd+Space 重开；候选未开时上下翻 shell 历史不触发自动补全，继续输入/删除后恢复。带修饰键的方向键和输入法 composing 交原输入组件处理。历史可从右键或 Ctrl/Cmd+Shift+H 搜索；全屏程序、未知输入状态不采集命令。异步接口保留供未来独立授权的 AI 使用，历史仍排最前，本轮不调用模型。说明跟随软件语言：英文原文，中文优先离线译文，未覆盖用本地化类型提示并在 tooltip 保留原文；自有文案走 i18n。详见 TERMINAL_ASSISTANCE。
- 分屏标题占满当前 pane 宽度，关闭按钮位于最右端。文件面板停靠菜单按内容收窄，“左侧 / 右侧 / 下方”前配对应方位图标。
- 远程文件可从“打开方式”选择本地可用应用，并按扩展名（无扩展名时按完整文件名）记住默认；双击使用默认应用。新编辑默认勾选保存同步，可随时取消；可靠的文档等待命令确认关闭后，最后一次保存同步完成且无冲突才自动结束。未知或转交式应用无法确认文档关闭时保留记录，用户手动结束。详见 EXTERNAL_EDITS。
- 激活 pane 用细 accent 边框/标题标记；不把未激活终端全文降到低对比度。
- splitter 可见线 1px、命中区 8px，hover 显示抓取；双击等分。拖动结束立即更新远端尺寸，不让动画反复触发 PTY resize。
- 打开面板用独立 repaint 区域；侧栏开合避免每帧重排所有终端字符，必要时动画期间固定终端网格，结束 fit。此策略须实测，不用动画掩盖耗时。
- 用户向上滚动查看输出时停止自动跟随；底部显示“回到底部”。新数据不抢选区或焦点。
- 连接中展示当前步骤；未知指纹或挑战以有焦点的对话框处理；失败原位显示错误、重试和编辑入口。
- SFTP 面板拖入文件先明确目标目录；命令终端上的文件拖放首期只提供显式上传菜单，不能把路径误输入远端 shell。

## 5. 弹层、命令面板与反馈

传输列表从顶栏传输按钮下方以锚定 popover 展开，沿窗口右边界避让，宽约 440、最大高 520（小窗口按可用空间收缩）；点击外部或 Esc 关闭。列表保留进度、暂停/继续、取消、重试与清理历史操作，列表本身可滚动；关闭弹层不停止传输。不再打开右侧整高抽屉。

弹层全部用 `lib/design/` 的自有组件，不用 Material 的 AlertDialog、PopupMenu、DropdownButton、SegmentedButton、Switch、Checkbox 外观（ADR-13）：对话框（`showAppDialog`/`AppDialog`）、菜单（`showAppMenu`/`AppMenuButton`）、下拉选择（`AppSelect`，长列表可搜索）、分段控件、开关、复选框、浮层（`showFlyout`）、右侧浮动面板（`showSideDrawer`）。它们组合 Flutter 原语（Route、Overlay、Focus、Shortcuts、Semantics），统一避让边界、Esc、焦点恢复和层级；外观是圆角、细边框、浅阴影，进出场 180 ms 淡入加轻微缩放或位移。模态框只用于需要即时决定的安全确认、认证与退出保护；一般编辑用浮动面板。

命令面板默认最大宽 640、高 480，居中偏上且适应小窗口。分主机、会话、动作结果；键盘上下选择时鼠标静止不抢选中，实际移动鼠标才切指针模式。支持 Enter 执行、Esc 返回原焦点。M4 用明确的“询问 AI”结果项或按钮，不因无匹配就发送查询文本。

Toast 只用于非阻塞结果，最多同时 3 条，同类批量传输合并。普通成功 3s，错误不因短暂超时丢失，保留在任务/状态区域。错误需要可重试动作和上下文，不只“出错了”。耗时 100ms 内提供状态反馈；短请求避免闪一下 skeleton，超过约 150ms 再展示加载占位。

## 6. 键盘与无障碍

优先级：模态输入 → 当前编辑控件/IME → 应用保留快捷键 → 终端透传。composing 时不触发业务动作。快捷键按上下文注册，设置中冲突检测；macOS 使用 Cmd 变体。

| 动作 | Windows/Linux 初值 | macOS 初值 |
|---|---|---|
| 命令面板 | Ctrl+Shift+P | Cmd+Shift+P |
| 新建连接 | Ctrl+Shift+N | Cmd+Shift+N |
| 关闭当前应用标签 | Ctrl+Shift+W | Cmd+W |
| 终端复制/粘贴 | Ctrl+Shift+C / V | Cmd+C / V |
| 终端搜索 | Ctrl+Shift+F | Cmd+F |
| 设置 | Ctrl+, | Cmd+, |
| 面板焦点轮换 | Alt+方向键（可修改） | Cmd+Option+方向键（可修改） |

Ctrl+C、Ctrl+W、Ctrl+K、Ctrl+B 默认透传终端；不沿用旧稿的 Ctrl+K 全局入口抢占 shell。列表里 Ctrl+C 为复制不影响终端。窗口/WM 占用组合以平台测试为准。

所有控件有可见 2px 焦点边框、语义标签和键盘操作；图标有 tooltip 与 screen-reader label，hover-only 操作在 focus 时也可见。弹窗 focus trap、关闭回原位置；Esc 不退出应用。错误/连接状态不能只靠颜色。缩放、系统大字、减少动画按上述设计实现，不作为发布门槛。

## 7. 组件归属与检查

design：AppDialog、AppMenu、AppSelect、AppSegmented、AppSwitch、AppCheckbox、Flyout、SideDrawer、IconRail、DockPanel、Tooltip 主题等通用组件；按钮和输入框沿用 Flutter 控件、由主题统一外观。优先组合 Flutter 原语，不重新实现基础焦点、文字选择与语义。

features：HostCard/HostRow/HostTree、TerminalPane、FileList、TransferRow、MonitorPanel、ApprovalCard 等带业务含义组件。复用不是把全部 Widget 放公共目录。

由作者实际使用检查，标准见 TESTING 的 U-01 与 P-02。

主机密钥管理只从侧栏“主机密钥”（Host keys）进入，保留导入与移除信任记录的功能；外观等设置页不再重复嵌入信任记录。
