# SSH 出站代理

左侧“代理”打开集中面板，管理 SSH 连接已有的 SOCKS5 / HTTP CONNECT 配置；端口转发仍管理 SSH 提供的 L/R/D 通路，两者不共用第二份代理库。

- 面板列出全局默认值、全部分组与主机，支持按名称、分组和有效代理端点搜索；即使当前直连也可配置。
- 每项显示有效代理和继承来源；编辑只修改该层的 proxy 字段，保留登录、端口、跳板、算法和其他元数据。支持继承、明确直连、自有 SOCKS5 / HTTP CONNECT。全局的“继承”回到内置直连。
- 主机有跳板时，实际出站代理取最外层跳板的配置。面板显示所经跳板和实际代理，并提供直接编辑该跳代理的入口，不把目标主机被忽略的代理宣称为当前路线。
- 新 typed 用例 `setHostProxy` / `setGroupProxy` / `setDefaultProxy` 在主机写队列内取最新对象，只 patch proxy，并要求 expectedRevision；编辑器初始化时固定 revision，与现有保存共用校验、原子提交和提交后旧代理凭据清理。冲突保留草稿并提示重新打开；已提交但凭据清理失败时提示部分完成，不能显示成完全未保存。
- 代理密码仍由连接流程按需询问，可由现有凭据流程记住；面板不读取、显示或持久化密码。编辑不拨号、不绕过主机信任，不影响已建立的会话、传输或转发；配置用于下一次连接。
- 复用现有 host/group/defaults 能力表示持久化代理变更，不新增浮层或表单瞬时状态的 Capability。现有能力默认不对 AI 开放。

验证使用临时主机库、合成凭据存储和组件测试，覆盖三态、字段保留、继承和跳板来源、revision 冲突、无效输入及写入失败。明确直连重新打开仍保持直连；切回继承后不验证或解析已禁用的旧草稿。用例见 `test/proxy_panel_test.dart`，实际结果与原生/真实代理验收边界统一见 TESTING §6。
