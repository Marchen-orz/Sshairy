# 自定义背景图片

软件界面与终端各有独立的背景图片和图片不透明度，设置即时显示，重启保留；各自的“恢复默认”同时清除该图片并恢复默认不透明度。未选择图片或图片无法读取时使用当前主题底色。只淡化背景图层，正文、终端字符、光标、选区、控件和认证弹窗不随之变透明。

- 两个设置槽为 `appBackgroundImage` / `appBackgroundOpacity` 和 `terminalBackgroundImage` / `terminalBackgroundOpacity`。默认图片为空，不透明度为 15%；图片不透明度范围 0%–100%。滑块拖动只改内存预览，松开后保存一次。
- 用户从本机选择静态 PNG/JPEG；文件筛选不能代替内容验证。输入最多 16 MiB，源图最多 40 百万像素；在完整解码前读取尺寸，再按比例下采样到最多 2 百万像素且最长边 2048。只取单帧图，拒绝动画。规范化 PNG 最多 8 MiB。
- 规范化副本存入应用支持目录的 `backgrounds/`，使用受限格式的随机不可变 ID。设置只存 ID，不存原始选择路径或图片数据。原图不修改、不删除；图片引用不向 AI 暴露，也不写诊断日志。
- 导入、重置串行执行。新副本先验证和发布，再提交该槽设置；保存失败移除本次新副本并保留先前设置。清理仅涉及本目录中符合 ID 格式的普通文件，保留两个槽当前引用；不跟随链接，不删除源文件。受管图片总量最多 32 MiB，未引用副本在后续操作时回收。
- 配置快照不包含图片副本。恢复的旧设置若引用已回收图片，界面回退主题背景，可重新选择图片；不把图片缺失当作配置损坏。
- 终端以主题色为背板，图片放在 renderer 下方，通过 renderer 的背景不透明度露出图片；不改变 ANSI 字符背景、反色、光标或选区的颜色定义。远端通过 OSC 11 指定背景色或开启全屏反色时暂停显示背景图并使用不透明终端背景，恢复后重新显示图片，避免 renderer 二次填充导致透明度叠加。软件背景位于工作区底层，导航、顶栏、卡片、文件数据区与浮层保持各自主题表面。
- 图片 Widget 仅在有效、可见时监听图片，隐藏的终端通过 `visible: false` 释放图片监听；规范化图与已有图片缓存预算共同限制内存。0% 时不解码图片。

验证包括导入类型/尺寸/容量限制、取消及无效输入不改变设置、失败提交回收新副本、两个槽的独立重置、未引用文件清理和缺图回退。原生文件选择器、真实窗口观感与解码峰值内存需实机验收，不能由合成测试代替。
