# 自定义背景图片

软件界面与终端各有独立的背景图片选择和图片不透明度，设置即时显示，重启保留；各自的“恢复默认”清除该槽的选择并恢复默认不透明度，已导入的图片仍留在图库里。未选择图片或图片无法读取时使用当前主题底色。只淡化背景图层，正文、终端字符、光标、选区、控件和认证弹窗不随之变透明。

- 两个设置槽为 `appBackgroundImage` / `appBackgroundOpacity` 和 `terminalBackgroundImage` / `terminalBackgroundOpacity`。默认图片为空，不透明度为 15%；图片不透明度范围 0%–100%。滑块按住拖动时，两个槽都逐帧重绘图片预览，只改内存，松开后保存一次。界面图片通过颜色的 alpha 调制更新绘制，不依赖替换静态透明度动画来触发重绘。
- 用户从本机选择静态 PNG/JPEG；文件筛选不能代替内容验证。输入最多 16 MiB，源图最多 40 百万像素；在完整解码前读取尺寸，再按比例下采样到最多 2 百万像素且最长边 2048。只取单帧图，拒绝动画。规范化 PNG 最多 8 MiB。
- 规范化副本存入应用支持目录的 `backgrounds/`，使用受限格式的随机不可变 ID。设置只存 ID，不存原始选择路径或图片数据。原图不修改、不删除；图片引用不向 AI 暴露，也不写诊断日志。
- 配置快照不包含图片副本。图库或槽引用的图片文件缺失时，界面回退主题背景，缩略图显示占位，可重新选择或移除；不把图片缺失当作配置损坏。
- 终端以主题色为背板，图片放在 renderer 下方，通过 renderer 的背景不透明度露出图片；不改变 ANSI 字符背景、反色、光标或选区的颜色定义。远端通过 OSC 11 指定背景色或开启全屏反色时暂停显示背景图并使用不透明终端背景，恢复后重新显示图片，避免 renderer 二次填充导致透明度叠加。软件背景位于工作区底层，导航、顶栏、卡片、文件数据区与浮层保持各自主题表面。
- 图片 Widget 仅在有效、可见时监听图片，隐藏的终端通过 `visible: false` 释放图片监听；规范化图与已有图片缓存预算共同限制内存。0% 时不解码图片。

## 图库

导入过的图片保存在两个槽共享的图库里，之后可直接切换，不必重新选择文件。

- 图库是设置 `backgroundGallery`：受管 ID 的有序列表，无重复，最多 24 项，只接受 `backgrounds/` 的 ID 格式（`agentExposed: false`，AI 看不到也改不了）。最新导入在前，切换选择不改变顺序。
- 保留集合是图库与两个槽引用的并集。图库功能之前写下的设置、或恢复的旧快照里，槽引用了图库没有列出的图片时，该图片按并集显示和保留；导入，以及替换、清除该槽选择的切换和恢复默认，会在同一次提交里把它写入图库，使它不会因槽改选而脱离并集。并集之外的受管文件是未引用副本。
- 设置页两个槽各显示同一组缩略图，选中状态按槽独立。点缩略图只改该槽的图片 ID，不重新导入、不改不透明度，点已选中的缩略图不做任何事。缩略图由受管副本按小尺寸解码，不另存文件，进入图片缓存的只有缩小后的位图。
- 导入：新副本验证、发布后，与图库新列表和该槽选择在同一次设置提交里写入；提交失败移除本次新副本，图库和选择不变。
- 容量：图库最多 24 项，受管图片总量最多 32 MiB。已满时导入失败并提示先移除图片，不自动淘汰已保存的图片；数量已满时不打开文件选择器。并集超过 24 项只可能出现在恢复旧快照后（保存的 24 项之外还有槽单独引用的图片），此时同样不淘汰：导入被拒绝；会让这类图片脱离并集的切换和恢复默认被拒绝并提示已满，需先移除图片（可移除它本身）；不会让它脱离的操作（如改另一个槽）照常进行。导入在容量检查前只回收未引用副本，选择、恢复默认和移除都不触发回收。
- 恢复默认：只清除该槽的图片选择并把该槽不透明度恢复默认，图片留在图库，另一个槽不受影响。
- 移除：缩略图上的移除按钮是删除图库图片的唯一途径，没有确认弹窗，因为原图未被改动、可重新导入。同一次设置提交把该 ID 从图库移除，并清除所有引用它的槽（这些槽回到主题底色，不透明度保持不变）；提交成功后才删除文件；其他图片，包括仅由槽引用的，不受影响。提交失败时图库、选择和文件都不变；文件删除失败时留作未引用副本，由下一次导入回收。切换选择、恢复默认和导入失败都不会删除已保存的图片。
- 所有变更（导入、选择、恢复默认、移除、保存不透明度）串行执行。清理和删除仅涉及本目录中符合 ID 格式的普通文件，不跟随链接，不删除源文件；目录本身是链接或普通文件时拒绝使用。

验证包括导入类型/尺寸/容量限制、取消及无效输入不改变设置、失败提交回收新副本、图库跨重启保留、切换选择不删除图片、两个槽的独立选择与重置（重置后图片仍在）、移除（含被两个槽引用、提交失败、文件删除失败）、数量和字节容量已满不淘汰、旧设置引用未列出图片（导入、切换、恢复默认、移除后都保留，并集超过 24 项时拒绝而不淘汰）和缺图回退。原生文件选择器、真实窗口观感、缩略图在满 24 项时的滚动与内存、解码峰值内存需实机验收，不能由合成测试代替。
