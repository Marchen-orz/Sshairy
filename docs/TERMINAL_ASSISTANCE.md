# 终端补全与命令历史

本文维护终端输入/候选交互、翻译与远程路径来源；三种 AI 入口的功能、触发、上下文/授权与预算统一见 [AI §4](AI.md)，纯 Dart 解析见 COMPLETION_ENGINE，静态数据与许可见 COMPLETION_SPECS，运行结果见 TESTING。AI 总开关默认关闭，配置并启用后行内生成与自动补全默认开启，可分别关闭；每项功能的高级设置仅筛选可用主机，默认全选，功能开启包含必要的有限同会话历史。具体契约见 AI §4.4，实现与验收状态见 ROADMAP/TESTING。内置常用命令仅在资源缺失或无规格时保守回退。

配置并启用 AI 后，可在空提示符按 Ctrl/Cmd+Shift+G，输入一句需求并点击生成；自动补全可在可靠 SSH 提示符行尾输入 `git st` 后停顿观察。自然语言识别仅点亮入口，不自动发模型；详细触发条件、延迟与预算统一见 AI §4/9。AI 请求可省略未知 cwd，也不为此主动查询；下文远程路径补全仍要求可信 cwd，不能借此放宽路径拼接规则。

## 数据与边界

- 现有历史/规格/路径候选不执行命令、不调用模型；M4 AI 补全由功能开关控制的无工具窄提供器请求，不能借翻译通道发送输入。说明文字可按用户设置交给翻译服务（见下）。按需读取随应用发布的 Fig 静态规格投影，包含命令/子命令/别名、选项、参数、静态取值、路径模板和说明。导入流程仅解释白名单 AST（含有界纯 helper），不执行规格 JS 或生成器；固定上游版本、保留来源和许可、统计未能静态提取的部分，见 COMPLETION_SPECS。Netcatty 的 GPL 代码与品牌素材不复制。
- SSH 与本地 Git Bash 默认匹配当前命令上下文；本地 CMD/PowerShell 仅提供会话历史与单行片段，不套用 POSIX 规格/引号编码，不调用远程路径来源。默认提示符只保守识别绝对路径的 CMD/PS 提示符或 Bash 行首 `$ `，自定义提示符仍须语义边界；未知/隐藏输入不记历史。规格支持嵌套子命令、选项参数、长选项等号、常见短选项组合、位置参数、引号和反斜杠。不猜测 shell 替换、重定向、管道或多命令的执行语义；不支持的上下文不提供规格/路径插入。
- 排序为通过校验的单个 AI 项、当前会话历史、规格/路径/片段和其他来源。按完整插入文本去重，总上限 200，历史最多 50，给其余来源保留空间；可视行数只限制浮层高度，不截断到 8 项。AI/历史以图标区分，不加多余标题。异步顶置不能改变当前选中身份；AI 无结果不保留空槽。片段仅本地匹配单行文本，不自动运行。
- 历史只在会话内存保存，最多 100 条、每条 2048 字符。前导空格、控制字符和多行不记录；可清空，关闭会话销毁；不读取远端 history，不进日志/配置。M4 行内生成与 AI 补全开启时，由窄端口提供必要的同会话有界安全投影，无独立历史开关，预算见 AI §9；不将完整历史交给通用 provider 或翻译，清空即取消相关请求/缓存。右键菜单和 Ctrl+Shift+H（macOS Cmd）打开 pane 内非模态候选样式浮层，提供搜索、上下选择与滚动，点击外部或 Esc 关闭；标题栏关闭按钮的点击区与右侧外边框保留 8 的内边距。非固定与固定状态均可拖动标题栏、通过右下角手柄调整大小；默认 440×360，最小 280×180、最大 720×560，位置和尺寸始终约束在 pane 边界，可用空间不足时优先收缩到 pane 内。位置与尺寸仅随当前 pane 状态保留，不持久化。固定按钮只使浮层保留在当前终端上层，点击外部或接受命令后不关闭；取消固定恢复原关闭行为，切页隐藏、关闭会话销毁。接受仍校验当前真实前缀/代次，只填入后缀、不清除已有输入、不执行命令；不能追加时不接受。
- 静态规格说明按软件语言显示：英文保留原文，中文有当前服务的历史译文时显示译文；未命中时保留英文原文，真实排队或请求期间在说明后显示紧凑加载动画，失败/关闭在线翻译/取消后移除动画，不用“子命令/选项”等类别代替现有原文。只有本身没有说明才用本地化类别。应用不打包离线译文词典或预设翻译缓存，缓存仅来自此前成功的翻译记录，tooltip 始终保留原文。设置可关闭在线翻译，已有译文仍可显示。不能把静态规格当作服务器已安装命令或支持全部选项的证明。
- 在线翻译只接受由补全适配器创建并登记的随包规格原始说明，不以可伪造的候选 source/标签/identity 判断授权。只发公开说明与固定语言对，不发命令草稿、历史、主机、路径、远程文件名、用户片段或外部提供器的任何文字。可见列表之外不预翻全库，后台/失焦/关闭的浮层取消自己的需求，共用请求保留其他窗口的等待者。
- 翻译设置提供 MyMemory（默认、免密钥）、DeepL、Google Cloud Translation Basic、Microsoft Translator，以及自定义 OpenAI 兼容 Chat Completions。翻译开关、当前服务与并发数量集中在同一设置区域；开关下第一项直接用下拉框选择服务，其专属字段在同一区域内展开，待保存改动由设置弹窗右下角统一提交，不再打开独立配置弹窗。配置以显式保存提交，编辑期间不改变活动服务；保存保留同一配置的修订冲突、空密钥保留与明确移除语义，不能因布局内联而覆盖外部更新或复用其他地址凭据；并发默认“自动（所有可见项）”，在有界 32 个活动请求内同时翻译实际可见词条，也可显式设置 1–32；排队词条最多 32 个，不预翻离屏候选。每次只调用选中的服务，失败不自动切换或向其他厂商广播。配置、并发数量和在线开关是用户专属设置，AI 不可读写；密钥只经 credentials 的窄端口进系统安全存储，表单不回填旧密钥，留空保留、明确移除才删除。内置服务地址固定；DeepL 区分 api-free/api，Microsoft 可填资源区域，不代替用户开通/付费账户。
- 自定义接口填 API 基础地址（如 `https://api.example.com/v1`）和模型，应用追加 `/chat/completions`。一般要求 HTTPS，仅 exact loopback 的 localhost、127.0.0.1、[::1] 允许 HTTP；禁止 userinfo、query、fragment。凭据绑定规范化完整基础地址，改地址不复用旧目的地的密钥，改模型可保留。请求仅包含固定翻译指令和公开说明，无 tools/远程上下文；只接受有界单行 assistant 文本，不执行模型输出。
- MyMemory 使用固定 HTTPS `get` 接口，可选填用户提供的有效邮箱，经 `de` 参数仅发给 MyMemory；不自动填入账号邮箱、不填虚构邮件。邮箱是非秘密的用户专属配置，缺失的旧配置按空邮箱兼容；最多 254 个 ASCII 字符并作常规邮件地址校验，不进日志、AI、密钥库或译文缓存身份。留空不发 `de`，其他服务不保留该字段；更改邮箱不改变译文身份与已成功的缓存。官方匿名额度 5000 字符/天、提供有效邮箱时 50000 字符/天，单次 500 UTF-8 字节（2026-11-09 核对官方 spec.php/usagelimits.php；不推断按 IP 或邮箱分桶）。服务请求按设置的并发上限启动、有界排队、禁重定向、超时真正中止；限额/网络/响应失败保留原文并冷却，错误内容不能写入译文缓存。其他服务的免费额度和计费以用户账户为准，不承诺全部免费。
- 译文缓存按服务身份、完整原文与目标语言精确匹配，原文任意变化即未命中、首次可见时重译；OpenAI 身份包含基础地址、模型和翻译协议版本，密钥不入缓存身份。应用缓存目录最多五个固定厂商槽，每槽最多 4096 条/2 MiB 序列化数据；同厂商改地址/模型只保留最近配置，避免随自定义地址无限增长。结果跨重启保存，设置与业务配置不包含译文；损坏/缺失/写失败可再生成，不阻塞启动或补全。自有按钮、状态和交互文案仍走 zh/en i18n。

接口依据（2026-11-09）：MyMemory `mymemory.translated.net/doc/spec.php`、`doc/usagelimits.php`；DeepL `developers.deepl.com/api-reference/translate/request-translation` 与官方 OpenAPI；Google `docs.cloud.google.com/docs/authentication/api-keys-use`、Translation v2 REST；Microsoft `learn.microsoft.com/azure/ai-services/translator/text-translation/reference/v3/translate` 与 authentication；OpenAI `developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create`。真实账号调用的验收状态单独记录，不以文档核对代替实际测试。

## 远程路径与层级浏览

路径来源位于 `terminal/domain/terminal_paths.dart`（规则、缓存、调度）和 `terminal/adapters/terminal_paths.dart`（SFTP）。它只回答目录元数据，TerminalSession 与界面决定查询时机和插入；不执行路径拼接 shell、不下载内容、不向终端写入。

### 查询与路径规则

- COMPLETION_ENGINE 的路径请求是入口：文件/目录模板在空参数时可列 cwd，未标模板的参数仅在用户输入显式路径时回退，不把主机、端口、用户、分支或容器空位当目录。`scp host:path`、`scp://…` 指向其他主机，不借当前连接列举；草稿解析器拒绝的重定向等上下文不查询。
- `RemotePathQuery{directory, prefix, foldersOnly}` 接受绝对 `/…`、`~`、`~/…`；相对输入由调用方以可信 cwd 经 `RemotePaths.absolute` 拼成绝对路径。拒绝 `~user`、`~+`、`~-`。前缀区分大小写，不含 `/` 或控制字符，最多 255 UTF-8 字节。
- 目录原串最多 4096 字符，规范化后最多 4096 UTF-8 字节、128 段；去空段和 `.`，保留 `..` 交服务器按物理路径解析，避免在符号链接处错误折叠。拒绝孤立代理项、NUL 和控制字符；仅开头的 `~` 表示家目录。
- `RemotePathResult` 返回展开后的绝对目录、连接 generation、cached、最多 200 个条目和 truncated。目录及指向目录的符号链接在前，之后按 UTF-16 码元区分大小写排序。匹配超过 200 或扫描未读完均标 truncated，没匹配到不证明目录中不存在。
- 条目含 name、kind（directory/file/symlink）、path、linkToDirectory。设备、管道、套接字按 file；目录或指向目录的链接可进入，断链/文件链接不再跟踪。`child`/`parent` 仅生成下一次 browse 路径，不写终端。
- 丢弃空名、`.`、`..`、含 `/`、NUL、C0/DEL/C1、换行、U+2028/2029、双向控制符（U+061C、U+200E/F、U+202A–E、U+2066–9）、U+FFFD 或超过 255 UTF-8 字节的名字；不可还原的字节不拿来插入。点文件仅在前缀以 `.` 开头时显示，foldersOnly 只保留可进入目录。

### 有界列目录

- 复用已认证 `TransportLease`，`openFiles()` 返回 foundation 的 `FileSystem`，关闭它只关自有 SFTP channel。普通 `list` 会完整读取并逐个 stat 链接，补全优先使用可选 `BoundedFileListing.listBounded(directory, maxScanned, accept, cancel)`，由 `SftpFileSystem` 通过流式 readdir 实现。
- 一次最多一个 READDIR 在途，批间检查取消；`.`/`..` 不计数。最多扫描 4096 个名字，遇第 4097 个即停止并返回 complete=false；恰好 4096 且随后 EOF 才算完整。名字被 accept 拒绝仍计 scanned，但不保留、不 stat；前缀、点文件和 foldersOnly 在扫描缓存上过滤，不扩大扫描范围。
- 只对范围内且名字合规的符号链接做一次跟随 stat，最多 16 个并行，不递归。不存在、无权限、成环等服务器状态按非目录；noConnection、connectionLost 和传输错误向外抛。链接密集目录最多需要约 256 批 stat，慢链路可能先超时。
- dartssh2 readdir 提前停止时不会公开关闭目录句柄；因此 complete=false、扫描失败或取消后必须关闭自有 channel，下一次重开。目录根本打不开时没有句柄，无需关；完整读完可以复用。`BoundedFileListing` 其他调用方也须履行这条契约。
- 未实现有界接口的测试替身/本机文件系统回退到完整 list 再截断，complete 如实报告；完整 list 已读完，不因结果截断额外关 channel。回退不具有内存上界，只有查询期限，不能冒称同样有界。

### 缓存、取消与寿命

- 缓存键为（连接代，展开后的目录），TTL 5 秒、最多 16 目录/16384 条目，LRU 淘汰。浏览器仅保留读取器前 4096 名字，多出按未读完处理；每目录默认最多缓存 4096 名字，超缓存预算仍答复但不缓存。只存规范名字、类型和 complete，不存大小、属主、时间；缓存命中仍保留 truncated。
- denied、notFound、timeout、failed 同样缓存 5 秒以免每键重试；unavailable、cancelled、invalid 不缓存。家目录 `home()` 为 SFTP realpath('.')，来源存续期间只取一次。
- 同目录等待者共享一次扫描，一次只列一个目录；新目录取代旧目录。单个调用方取消只撤销自己的等待，最后一个等待者离开才中止扫描。整体查询（含 home）默认 3 秒，读取器每请求也有同样期限；取消或超时真正关闭自有 channel，不能只用 Future.timeout 停止等待。
- channel 惰性打开、空闲 10 秒关闭；租约丢失或 dispose 立即关闭。一个来源绑定一个（租约，连接代），连接成功创建，shell 结束、换租约、重连或关闭时 dispose；来源不 acquire、不 release、不拨号，不绕过 HostTrustService，旧缓存随代失效。新草稿取消旧需求。
- 错误只携 kind：invalid（参数）、unavailable（租约/来源/通道不可用）、denied、notFound、failed、timeout、cancelled。界面用简短本地化状态区分加载、空目录和失败，不阻断终端，不把失败当空成功，不记录原始异常、路径或名字。

### 身份与插入边界

- 相对目录必须来自可靠 OSC 7 或已验证目录提供器；未知时不把 SFTP 默认目录冒充 shell cwd。`~` 是 SSH 登录用户的家目录，切换用户或自定义 HOME 后可能与 shell 不同；已知不一致时不拼相对路径或展开 `~`。服务器以登录用户身份列目录，不作为内层 shell 的权限判断。
- 当前从 OSC 7 或外层 shell 查询取 cwd，尚不能完整辨认 tmux、su、sudo -i、嵌套 ssh、自定义 HOME。不能把上述来源要求写成已实现的身份识别；已知这些场景应关闭候选或用明确绝对路径，可验证的 shell 身份协议仍待实现。
- 目录进入/返回只改变候选状态，不发退格、方向键或预填路径；最终确认按当前引号上下文安全编码，只追加经验证的后缀。列表显示位置与返回入口；目录优先、按前缀过滤。
- 远端名字是不可信数据，只显示和插入，不执行、不落盘、不进日志/诊断/AI；`CommandCompletionProvider`（含未来 AI）拿不到目录列表。

## 键盘与鼠标

- 在已识别且可编辑的提示符行尾首次出现候选后，默认选中首项；M4 迟到 AI 顶置仍保留原选中对象，不重置为新首项。上下键在候选中移动并滚动保持可见，Tab 确认规格完整命令/参数/文件词后自动补一个空格（补齐未闭合引号），目录保留 `/` 继续下钻，`--选项=` 等连写值不补空格，历史/片段/AI 整句保持自身文本，不机械添加空格。左右键只有存在可进入的目录/命令下一级或已浏览的上一级时才接管，否则关闭候选并交给终端移动光标。
- 目录点击或右键进入；文件点击/Tab 确认；命令和普通参数点击/Tab 补入文本。Enter 关闭候选并按原终端行为提交当前已回显命令，不隐式接受另一条候选。Esc 关闭当前草稿候选，原有 shell 按键恢复；草稿变化后重新显示。Ctrl/Cmd+Space 可重新打开当前草稿候选。
- 候选未打开时，上下键透传 shell 翻历史；翻历史的回显不自动弹补全，直到用户继续输入/删除、提交新命令或明确 Ctrl/Cmd+Space 重开。该抑制属于会话输入意图，迟到的目录/规格查询也不能重新弹出。
- 路径补全与文件面板共享会话的工作目录查询：已有查询在途时等待同一个结果，不把尚未返回的空值当作查询结束；命令提交或连接代变化后，旧查询不能发布目录。
- 输入文字继续交给终端；已有但未回显的输入立刻撤销候选，不从发送按键重建命令。Ctrl/Alt/Meta 修饰的方向键等保持原有终端行为。输入法 composing 时原输入组件优先，不拦截输入法的方向键与 Tab；失焦、搜索、备用屏幕、未知提示符和命令运行时不接管按键。
- 同一草稿的异步结果按候选身份保留选中项；如果选中项消失则不默默把 Tab 接受对象换成另一项，待用户重新移动后选择。鼠标实际移动才改变选中项，避免滚动后静止指针抢选择。

## 定位与插入保护

- 浮层锚在当前 pane 实际光标右边缘，下方不够翻上方，右侧不够收进边界；随回显、滚动、布局和界面缩放更新。宽度按候选文本收缩并设紧凑上限，命令列与解释列相邻、解释左对齐并省略；滚动条仅保留一份必要槽位，不重复叠加右内边距或额外空列；悬浮解释显示完整说明，长命令也可悬浮查看。光标滚出视口时隐藏；浮层不抢输入焦点。
- 只从终端已回显的行提取命令。优先 OSC 133/633 输入边界，普通提示符兼容 `user@host:路径$ ` 与 `[user@host 路径]$ `。未知、折行、多行、行中光标和备用屏幕不采集。普通提示符是远端文本，不能当作远端安全边界。
- 确认时再次核对 shell generation、草稿 revision、实际回显前缀以及候选来源。只发送经过校验的后缀，不发送换行、退格或删行控制序列。目录导航也不得突破后缀约束；无法只追加表达的选择不能确认。
- 通用 `CommandCompletionProvider` 只接收本次草稿、可选 cwd、generation/revision 和取消令牌，不获 shell 句柄、完整历史或目录列表。M4 另由 app 注入 AI 窄端口，对应功能开启时只附该请求需要的近期历史投影与已知环境/目的地修订；不能扩大通用 provider 的数据权限。模型结果必须通过客户端后缀校验与失效检查；只接受后缀，不改写已输入词。
- 行内自然语言生成不走后缀候选协议：本地识别只亮 pane AI 图标，点击/快捷键后请求，加载与结果在本地 overlay。真实终端文字已经发给远端，不能自动 Ctrl-U/退格清行；默认先展示结果，用户清空后经空行/代次/回显检查再填入。显式在空提示符进入的本地输入层可以直接替换其自有草稿；最终接受仍不发 Enter。详细状态、发送策略与降级见 AI §4.2，不将逐键输入改成 Capability。
