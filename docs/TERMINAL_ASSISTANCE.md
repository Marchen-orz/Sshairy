# 终端补全与命令历史

2026-11-08：候选是本地辅助输入，不执行命令。默认使用内置常用命令和当前终端会话的内存历史；不读服务器历史文件、不安装 shell 脚本、不联网调用模型。

- 根据终端模型中已经回显的当前行提取命令。优先使用 OSC 133/633 的输入边界；普通 bash/zsh 兼容 `user@host:路径$ `、`[user@host 路径]$ ` 形式的提示符。未知提示符、折行、多行、光标不在行尾、备用屏幕和命令运行期间不自动补全。
- 不从按键、PTY 输入回调或终端自动应答重建命令。只有用户在已识别提示符按 Enter 时，才把已回显的命令加入历史；无回显密码没有可采集文本。提交后立即关闭输入窗口，直到新的提示符出现。提示符由远端控制，这不是远端安全边界；显示在终端里的命令也可能包含敏感内容，因此历史仅在本会话内存保存、最多 100 条/每条 2048 字符、可清空、关会话销毁，不进入日志、文件或 AI。
- 键入后约 180 ms 更新最多 8 个候选，候选浮层不抢焦点。鼠标点选补上当前命令的后缀。Ctrl+Space（macOS 为 Cmd+Space）显式进入候选键盘选择，此时上下键、Tab/Enter 选择，Esc 关闭；没有显式进入时，Enter、Tab、上下键仍发给 shell。Enter 选候选只插入，不附加换行。输入法 composing 由原终端输入组件处理，候选不接管输入法。
- 右键菜单的“命令历史”和 Ctrl+Shift+H（macOS 为 Cmd+Shift+H）打开可搜索列表，可复制、插入或清空。右键设为粘贴时，Shift+右键仍可打开菜单。历史选择只可补全当前已回显的前缀，或在已识别的空命令行插入；其他情况保留列表的复制能力，不猜测远程 readline/vi 的删行行为。
- 已提交行按缓冲行身份识别，换行与清屏重绘后可识别下一提示符，不依赖会被回滚复用的行号。清空历史立即撤销旧候选，关闭会话清空历史和候选副本。主键盘与数字键盘 Enter 都可提交；提取回显保留组合字符。
- 键盘候选模式绑定本次请求，草稿变化或失去焦点就退出；浮层避让当前输入行。已发送但尚未收到回显的输入立即撤销候选，不从发送内容重建命令。
- 插入时再次核对原 shell generation、当前回显草稿修订和前缀；重连、继续输入、切到其他程序后的旧结果全部失效。候选和历史不自动执行，不能携带换行或控制字符。
- `CommandCompletionProvider` 是纯 Dart 的异步候选端口，只接收本次草稿、光标、可选 cwd、generation/revision 和取消令牌，不获得 shell 写入能力或完整历史。后续 AI 必须由应用装配在独立授权后注入；当前没有 AI 提供器，也不会自动发送命令或历史。请求防抖、取消且丢弃迟到结果。

## 上下文候选与定位

2026-11-08：参考固定版本 Netcatty 的候选交互（证据见 NETCATTY_REVIEW），目录与算法独立实现，未复制 GPL 代码、Fig 规格或品牌素材。

- 内置静态 CLI 目录覆盖文件、文本、网络、进程、systemd、包管理、Git、容器和终端复用等常用命令。命令树按已输入命令选择子命令、选项和少量固定参数，例如 `tmux `、`git stash `、`docker compose up -`。不访问服务器枚举可执行程序、路径、容器或服务；静态条目不代表目标服务器已安装或支持该参数。
- 只解析普通单行词与有限路径字符；引号、转义、变量展开、管道、重定向、连接命令、未知上下文不猜测。需要参数的选项先消费其参数；按完整文本去重并保留用户输入前缀。短显示词覆盖实际补入内容，旁边显示可用的中英文简述。一次最多 8 项；会话历史优先但最多先占 5 项，给目录候选留位置。
- 候选位于当前终端 pane 内，锚在 renderer 实际光标右边缘，优先下方、底部不够翻上方、右侧不够向左收进边界。随输入回显、滚动、分屏与界面缩放更新，光标滚出视口则隐藏。列表过高时可滚动，键盘选中项保持可见。
- 异步来源保留 `ai` 类型，排序为 AI、当前本地候选、其他提供器；合并仍执行前缀/单行/显示文本检查和数量限制。同一草稿的迟到结果按完整插入文本保留选中项；该项被移出列表则退出候选键盘模式，不默默接受另一个条目。本轮没有接入模型或发送命令。

普通提示符识别无法覆盖所有 shell 主题或运行在主屏幕上的交互程序。未能确定可编辑命令行时宁可不插入；系统原有 Tab、Ctrl+R 和 shell 自带历史仍可用。真实服务器和输入法的验收范围写入 ROADMAP，不由模拟通道测试推定。
