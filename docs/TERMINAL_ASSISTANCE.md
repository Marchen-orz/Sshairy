# 终端补全与命令历史

2026-11-08：已接入规格库、上下文解析、多来源合并和文件层级浏览，实际验证以 ROADMAP 为准。取代此前手写 100 个根命令、总数截断 8 条及 Ctrl+Space 才能选择的方案；旧手写库仅在资源缺失或无规格时保守回退。

## 数据与边界

- 补全不执行命令、不调用模型。按需读取随应用发布的 Fig 静态规格投影，包含命令/子命令/别名、选项、参数、静态取值、路径模板和说明。导入流程仅解释白名单 AST（含有界纯 helper），不执行规格 JS 或生成器；固定上游版本、保留来源和许可、统计未能静态提取的部分，见 COMPLETION_SPECS。Netcatty 的 GPL 代码与品牌素材不复制。
- 默认匹配当前命令上下文；支持嵌套子命令、选项参数、长选项等号、常见短选项组合、位置参数、引号和反斜杠。不猜测 shell 替换、重定向、管道或多命令的执行语义；不支持的上下文不提供规格/路径插入。
- 候选排序为当前会话历史、其余来源（未来独立授权的 AI、规格、路径、片段和其他提供器）。按完整插入文本去重，总上限 200，历史最多 50，给其余候选保留空间；可视行数只限制浮层高度，不截断到 8 项。历史来源以图标区分，避免额外标题。片段仅本地匹配单行文本，不自动运行。
- 历史只在会话内存保存，最多 100 条、每条 2048 字符。前导空格、控制字符和多行不记录；可清空，关闭会话销毁；不读取远端 history 文件，不进入日志、配置或 AI。右键菜单和 Ctrl+Shift+H（macOS Cmd）仍可打开可搜索历史。
- 静态规格说明来自第三方数据，原文显示；自有按钮、状态、路径导航和交互文案走 zh/en i18n。不能把静态规格当作服务器已安装命令或支持全部选项的证明。

## 文件层级浏览

- 参数要求文件/目录，或用户明确输入路径前缀时，读取当前已认证连接的独立 SFTP 通道，只列目录元数据，不执行路径拼接 shell，不下载文件内容，不另行绕过主机信任建立连接。与文件面板/传输通道相互独立。
- 相对路径使用当前会话可靠的目录信息；根路径、用户主目录与相对目录严格区分。目录未知时不把 SFTP 默认目录冒充当前 shell 目录。路径缓存绑定 shell/连接代次，TTL 5 秒、最多 16 个目录，查询有超时、扫描和结果上限；关闭、重连和新草稿撤销旧查询。
- 文件候选采用层级浏览：目录可进入、返回父层，目录优先，按输入前缀过滤，未输入点时隐藏点文件。目录浏览只改变候选框状态，不向终端发送退格、方向键或预填路径。最终确认时一次补入选定路径的后缀；路径含空格、引号或 shell 特殊字符时按当前引号上下文编码。
- 层级列表显示当前位置及返回入口，加载、空目录、失败使用简短状态。失败不影响终端连接，绝不把失败当成空目录成功。仅列元数据，不把文件名/目录发给 AI 或日志。

## 键盘与鼠标

- 在已识别且可编辑的提示符行尾出现候选后，默认选中首项；上下键在候选中移动并滚动保持可见，Tab 确认。左右键用于候选层级：右键进入选中目录或命令下一层预览，左键返回上一层；无下一层/上一层时消费该键以免意外移动远端光标。
- 目录点击或右键进入；文件点击/Tab 确认；命令和普通参数点击/Tab 补入文本。Enter 关闭候选并按原终端行为提交当前已回显命令，不隐式接受另一条候选。Esc 关闭当前草稿候选，原有 shell 按键恢复；草稿变化后重新显示。Ctrl/Cmd+Space 可重新打开当前草稿候选。
- 输入文字继续交给终端；已有但未回显的输入立刻撤销候选，不从发送按键重建命令。Ctrl/Alt/Meta 修饰的方向键等保持原有终端行为。输入法 composing 时原输入组件优先，不拦截输入法的方向键与 Tab；失焦、搜索、备用屏幕、未知提示符和命令运行时不接管按键。
- 同一草稿的异步结果按候选身份保留选中项；如果选中项消失则不默默把 Tab 接受对象换成另一项，待用户重新移动后选择。鼠标实际移动才改变选中项，避免滚动后静止指针抢选择。

## 定位与插入保护

- 浮层锚在当前 pane 实际光标右边缘，下方不够翻上方，右侧不够收进边界；随回显、滚动、布局和界面缩放更新。光标滚出视口时隐藏；浮层不抢输入焦点。
- 只从终端已回显的行提取命令。优先 OSC 133/633 输入边界，普通提示符兼容 `user@host:路径$ ` 与 `[user@host 路径]$ `。未知、折行、多行、行中光标和备用屏幕不采集。普通提示符是远端文本，不能当作远端安全边界。
- 确认时再次核对 shell generation、草稿 revision、实际回显前缀以及候选来源。只发送经过校验的后缀，不发送换行、退格或删行控制序列。目录导航也不得突破后缀约束；无法只追加表达的选择不能确认。
- `CommandCompletionProvider` 只接收本次草稿、可选 cwd、generation/revision 和取消令牌，不获得 shell 句柄或完整历史。历史和远端路径保留在本地确定性流程；未来 AI 独立授权后注入，不能借此扩大权限。
