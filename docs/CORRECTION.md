# 2026-11-06 纠偏与桌面外壳调整

用户要求：先纠偏，再由 Codex 重做可爱且能表达 SSH 产品特性的图标、提亮默认配色，改为无系统标题栏的自绘窗口，最后继续非 AI 的剩余工作。本文是实施约束；完成和验证结果仍登记 ROADMAP，不因本文存在而视为已完成。

## 架构与数据保护

- Capability 定义与面板数据源放在 app 的组合适配层，依赖各 feature 的 api.dart。业务 feature 不反向依赖 capabilities；typed 用例仍由各 feature 持有。依赖检查增加这条约束。
- credentials 对外提供按用途的窄凭据端口和密钥管理用例，不导出平台安全存储实现；使用 SecretRef，禁止任意字符串存取秘密。删除密钥的引用检查在 application 用例里执行并在提交前重验，由组合层注入主机引用查询，避免 credentials/hosts 循环。密钥元信息先落盘再发布，最后回收秘密。
- 池键纳入凭据与信任变更世代；遗忘信任、替换凭据后新 acquire 不复用旧世代连接。已有终端不静默断开。世代只在收回信任或凭据时递增（首次信任与首次保存凭据不算），详见 CONTRACTS 池 key 一节。
- JsonFile 区分缺失、损坏、未来版本和 IO 失败。只有缺失能作为初始空配置；其余不得被后续普通 write 覆盖。损坏自动恢复必须先保护原件，验证候选快照的版本与结构，不得把解析成功等同领域有效。失败保持原件和写保护，不静默初始化。旧 schemaVersion 1 文件无 revision 时按 0 读，保存写递增 revision；expectedRevision 冲突拒绝。持久化用例逐步接入同一规则，不宣称跨文件事务或完整迁移框架。
- 所有退出入口共用关闭协调：列出活动转发、传输和未上传稿件，取消退出保持工作；确认后停止接收新任务、收束通道、等配置写入、最后关闭 transport。超时不冒充操作已完成。保存/停止失败提示并允许重试或显式结束。

## 桌面外壳与视觉

下列配色和图标方向为 2026-11-06 的历史要求；2026-11-07 作者提供完整六套品牌素材后，视觉部分以 UI §2 与 BRAND 为准，窗口与退出约束仍适用。

- Windows 隐藏系统标题栏，Flutter 绘制紧凑的标题/标签行及最小化、最大化/还原、关闭按钮。通过平台适配层保留原生拖动、双击最大化、边缘缩放、最大化工作区边界和 DPI 行为；关闭按钮与系统关闭请求都走同一退出协调。其他桌面平台保留可编译的适配边界，实测范围写明。
- 标题行背景与应用表面融合，避免再叠一条系统顶栏。主操作保留主机库、文件、标签及必要会话操作；转发、片段等收进明确的更多入口或导航，避免工具图标不断增长。一般规则编辑使用统一抽屉，安全和退出确认使用模态对话框。
- 默认 accent 改为明亮冰蓝：Light #06ADC8 / Dark #5ADDEB；前景按对比度选择深色，保留绿/紫/橙主题。背景采用低饱和冷灰，不用深钴蓝大色块；终端光标/选区随 accent 与模式适配。
- 图标由 Codex 独立绘制新的 SVG：柔和饱满的终端精灵，`>` 与光标为主要识别元素，辅以简洁连接线/节点表达 SSH；小尺寸保留轮廓和命令提示符，避免复杂电路装饰。源文件与桌面图标同源导出，提供明/暗背景与 16–256 px 预览核对。
