## 2. 使用真实服务器的规则

这是作者在用的服务器，测试不能影响它：

- 需要连接时向作者要凭证，只经同一命令的环境变量提供，不写入任何文件、文档、仓库、日志、测试或提交。
- 不修改 `/etc/ssh` 等系统配置，不重启现有服务，不动测试目录外的文件；不触碰作者的常驻进程，不用结束进程功能测试它们。
- 文件测试只在 `~/sshairy-test/` 的独立子目录内，结束后清理。
- 转发用空闲高位端口，默认 loopback，结束后确认释放。
- 认证失败仅少量几次，避免 fail2ban 或账号锁定；主机密钥变化改本地测试信任记录，不换服务器密钥。
- 真实服务器回归注入临时 dataDir 和内存凭据，不访问实际 OS 凭据库。Windows 同命令设 `SSHAIRY_TEST_ISOLATED=1`，runner 固定 Skia、不读真实 settings.json；Dart 侧仍须独立注入目录。
- 内存凭据替身只验证 SSH/SFTP 与业务流程，不能推定 OS 存储的加密、失败和重启行为已通过。
- 超过 1 GB 流量、sudo、临时开 sshd 或改 authorized_keys 等操作先单独取得授权；已有某次授权不作为以后任意测试的授权。

多因子、代理等环境没有的场景，实际用到再测或标未验证，不为补验收而改现有服务。
