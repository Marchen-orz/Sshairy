# 测试

v0.3 · 2026-11-06。sshairy 是开源软件，主要供作者自用，不提供兼容性和可用性保障（ADR-10）。测试以作者的真实环境为准，保持简单。

简化的是测试规模和兼容范围，不是安全规则：SECURITY 的要求照常写进代码。

## 2. 使用真实服务器的规则

这是作者在用的服务器，测试不能影响它：

- 需要连接时向作者要凭证。凭证不写入文档、仓库、日志或测试代码。
- 不修改 `/etc/ssh` 等系统配置，不重启现有服务，不动测试目录外的文件。
- 文件测试只在 `~/sshairy-test/` 内进行，结束后清理。
- 转发测试用空闲高位端口，默认绑定 loopback，结束后确认已释放。
- 认证失败只试少量几次，避免触发 fail2ban 或锁定账号。
- 模拟主机密钥变化时改本地信任记录，不换服务器的密钥。
- 超过 1 GB 流量的测试、需要 sudo 或临时开 sshd 的操作，先问作者。

多因子、跳板、代理等服务器上没有的场景，作者实际用到时再测，否则标“未验证”。

2026-11-07 主机库动作轮换：只跑了组件测试（固定随机种子，假时钟推进 45 秒，图片解码在 `runAsync` 中完成），确认切换前后各只剩一张动作图、隐藏时两个周期不换、返回立即换且无淡出、减少动态效果时不换。未构建预览入口，真实窗口中的淡入淡出和各动作在框内的观感未截图检查。

2026-11-07 退出与窗口按钮：使用独立临时数据目录的 Profile 探针（无会话），只向己方窗口投递 WM_CLOSE，经本地探针接口按下确认。修复前确认后 Dart 清理即刻完成，但窗口仍停留 2.04 s 才消失，2.12 s 进程退出，冻结来自消息循环结束后的引擎拆除；修复后确认后 0.02 s（第一次轮询）窗口已隐藏，进程 2.27 s 退出，剩余拆除在不可见状态完成。有 SSH 会话时作者报告约 10 s 冻结，本轮未连服务器复测该场景。窗口按钮 PrintWindow 截图确认 200% 缩放下关闭图标中心距右缘 26 逻辑像素（右边距 8 + 半宽 18）；投递给窗口的 WM_MOUSEMOVE 不触发 Flutter 悬浮，悬浮圆角和危险色由 widget 测试覆盖，真实悬浮外观待作者亲测。探针入口和 Profile 输出已删除。

2026-11-07 导航拖宽与装饰：Debug 预览入口使用临时数据目录（0、3、4 台虚构主机，中文界面），只操作己方进程并用 PrintWindow 截图。检查了冰蓝浅/深的空主机库、展开导航 200 与 280 宽度、樱花粉深色和冰蓝浅色的右下水印、密钥/端口转发/片段浮层及传输浮层的空列表动作、薄荷绿深色浮层。初版暗色 45%–60% 的角色偏灰，提高到 60%–72%；水印初版贴近底边且浅色偏重，改为底部留 16、浅色 12%。预览入口与 Debug 输出已删除。导航拖动只由组件测试驱动（鼠标指针事件），真实窗口拖动待作者亲测。
