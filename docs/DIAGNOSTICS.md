# 诊断日志（一期）

按 SECURITY §1/§7 落实本地、有界的诊断记录。日志不自动上传；M4 能力调用审计另行实现，诊断日志不能冒充审计。

- 只接受枚举形式的区域、操作和结果，以及整数耗时；记录 UTC 时间。接口不接受自由文本、异常对象、堆栈、终端输出、命令、路径、地址、URL、主机标签、SecretRef 或请求参数。通过结构限制避免依赖关键词过滤来保护秘密。
- 主程序在应用支持目录的 `logs/` 中初始化；连接拨号、传输终态及未处理的 Flutter/异步错误只写上述元信息。不修改错误的业务语义，不把编程错误映射为网络成功。
- 最多 5 个文件，每个 2 MiB（含当前文件）；单写队列轮转。等待写入的记录最多 256 条，超出时只累计丢弃数量，写入下一条时记录数字。错误洪水不形成无界内存队列。
- 诊断写入失败关闭本次进程的记录器，保留既有日志，不引发递归异常或阻断连接/配置/退出。`idle` 可供退出等待待写记录，日志失败不冒充业务保存失败。
- 左侧“日志”打开本地诊断查看面板，显示最近最多 500 条记录（新记录在前），可按区域/结果筛选、刷新、暂停自动刷新及复制选中记录。复制只用解析后的枚举元信息，不复制原始 JSON 或任意字段。
- 历史读取与写入/轮转共用串行队列，读取固定 `diagnostic-0.jsonl` 至配置的最后一份；拒绝日志目录/文件的符号链接和超出配置大小的文件。每次最多扫描现有容量上限，格式损坏、未知枚举或额外字段的行跳过并提示数量，不向界面暴露原始行或读取异常。
- 写入完成或写入器停用时只发送不含内容的变化通知。面板合并通知并重新读取有界快照，不把历史快照和增量列表拼接，因此轮转及读取期间的新写入不会造成重复；暂停时保留当前有界列表，恢复后重新读取。面板关闭取消订阅和计时器。
- 不保留原始堆栈意味着当前只能定位区域、操作和时序；后续若需更详细的堆栈，必须先设计不包含源路径/异常消息的安全投影。此轮不启用终端录制，也不增加导出到外部服务的入口。

自动验证用例覆盖轮转容量、排队上限、最近记录顺序与条数限制、损坏/额外字段/超长行跳过、安全复制投影、历史读取与实时通知交错、写入失败不影响调用，以及面板的暂停/恢复、筛选、读取失败重试和在途快照丢弃。读写均拒绝固定轮转路径上的非普通文件；符号链接回归在支持创建链接的平台运行，Windows 用例显式跳过（创建链接取决于系统权限）。本轮用例是否实际通过以 ROADMAP 交接验证为准。真实服务器操作与秘密扫描结果另记 ROADMAP，不能由单元测试推定。
