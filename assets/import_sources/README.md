# Import source marks

These eight small SVGs were drawn independently for sshairy on 2026-11-08 to identify import sources. They are simplified visual cues, not official logo files or exact reproductions. No Netcatty code, assets, downloaded image files, fonts, or embedded raster images were used.

- OpenSSH: pufferfish and key.
- PuTTY: linked monitors and lightning.
- MobaXterm: multicolour terminal window.
- SecureCRT: terminal and padlock.
- Xshell: red shell spiral.
- FinalShell: blue terminal/F mark.
- Tabby: tabby ears and terminal prompt.
- CSV: generic green file/table, not a software logo.

Names and any associated marks identify the corresponding software; they do not imply affiliation or endorsement. The source tiles retain text names for accessibility. The SVGs are loaded only from bundled assets through `hosts/adapters/import_source_icon.dart`.
