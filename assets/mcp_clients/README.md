# MCP client marks

These four small SVGs were drawn independently for sshairy on 2026-11-19 to identify MCP clients in settings. They are simplified visual cues, not official logo files or exact reproductions. No Netcatty code, assets, downloaded image files, fonts, or embedded raster images were used.

- Claude Code: orange asterisk.
- Codex: dark terminal prompt.
- Zcode: blue Z tile.
- DeepSeek Harness: blue whale.

Names and any associated marks identify the corresponding software; they do not imply affiliation or endorsement. Each tile's tooltip and semantics carry the client name. The SVGs are loaded only from bundled assets through `app/mcp/adapters/client_icon.dart`.
