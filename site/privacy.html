Privacy Policy.

Sshairy is a local-first, open-source SSH client. We do not operate user accounts, cloud sync servers, analytics, or advertising SDKs.

Last updated: November 27, 2026 · Applies to Sshairy (Windows, macOS, Linux, Android) and sshairy.marchen.top

Zero TelemetryNo usage tracking, crash uploaders, ads, or developer backend servers.
OS-Backed SecretsPasswords, private keys and API keys stay in your OS secure storage only.
Explicit ConnectionsNetwork traffic goes only to servers, AI providers, or devices you configure.

1. Data We Do Not Collect

The Sshairy developer does not collect, sell, rent, or receive your personal data, SSH host configurations, credentials, terminal sessions, files, or AI conversations. Sshairy requires no sign-in or cloud account, and ships with no third-party analytics or ad tracking SDKs.

2. Data Stored Locally on Your Device

  • Configuration & Workspace Data: Hosts, groups, identities, known-host trust records, snippets, port-forwarding rules, layouts, settings, and local snapshots are stored as JSON files in your OS application data directory.
  • Sensitive Credentials: SSH passwords, private keys, key passphrases, AI/translation API keys, and Device Link Ed25519 identity seeds are stored exclusively in OS secure storage (Windows DPAPI, macOS Keychain, Linux Secret Service, or Android Keystore). Configuration files store only opaque references (SecretRef), with no plaintext fallback.
  • MCP Client Access Token (Opt-In): If you explicitly enable an external MCP client (such as Claude Code, Codex, Zcode, DeepSeek Harness, or Antigravity) under Settings → MCP / Skill, Sshairy writes a revocable loopback access token to that client's local user configuration file so it can connect to Sshairy locally. Disabling the client removes and revokes the token.
  • Diagnostic & Audit Logs: Bounded, redacted diagnostic logs and MCP audit logs stay locally on your device. Passwords, private keys, raw headers, and secrets are excluded from logs and are never uploaded automatically.
  • Temporary Files: External-editor temporary copies and .part transfer files live in user-private or destination directories and are cleaned up after completion.

3. Network Connections & Third-Party Services

Sshairy only initiates outbound network requests for features you configure or trigger:

  • SSH, SFTP & Forwarding: Connects directly to the SSH servers, jump hosts, and proxies you configure. Host-key verification runs before authentication on every connection path.
  • Airy AI Features (Off by Default): AI stays disabled until you enter your own Anthropic or OpenAI-compatible API endpoint and key. When you send a message, run an inline task, or trigger AI completion, only the bounded context, approved tool results, or explicitly attached files/images (images are re-encoded to strip metadata) are sent directly to your chosen model provider. SSH passwords, private keys, and stored secrets are never sent to AI models. Data sent to your chosen provider is governed by that provider's privacy policy.
  • Optional Completion Translation: If you enable online translation for shell completion descriptions, Sshairy sends only the bundled public command description text and target language — never your commands, hostnames, paths, or history. If you optionally enter an email for MyMemory, it is sent only as MyMemory's de query parameter.
  • Device Link (Desktop ↔ Mobile, Off by Default): When enabled, Device Link communicates directly over your local network or user-specified address using end-to-end encryption (X25519 + Ed25519 + XSalsa20-Poly1305). Optional LAN discovery broadcasts only protocol metadata, device ID, device name, and port — never hosts or secrets. Password sync requires explicit confirmation on the desktop before transfer.
  • Release Update Checks: The app (and this website) may query the public GitHub Releases API (api.github.com/repos/Marchen-orz/sshairy/releases/latest) to check for newer versions and download official release packages when you choose to update.

4. Android App Permissions

Sshairy for Android requests permissions only when needed for the feature you use:

  • Network & Vibration: Used for SSH/SFTP/AI connections, optional LAN Device Link discovery, and haptic feedback.
  • Camera (Optional): Requested only when you tap QR scan to pair with your desktop. Images are processed locally to read the pairing code and are never saved or uploaded.
  • Notifications & Foreground Service (Optional): Requested only when you enable background keep-alive for active SSH/Link sessions or remote Airy/MCP approval alerts.
  • Biometric Authentication (Optional): Used solely for the local app lock when enabled; biometric templates are handled exclusively by Android and never accessed by Sshairy.
  • Storage / All Files Access (Optional): Requested only if you choose to browse full local storage or transfer local folders between your phone, desktop, and SSH servers. Without it, Android's system file picker remains available.
  • Never Requested: Sshairy does not request location, contacts, phone state, SMS, or advertising IDs.

5. Website (sshairy.marchen.top)

This website is a static site with no cookies, no third-party analytics, and no advertising trackers. It uses browser localStorage solely on your device to remember your chosen color theme, light/dark mode, language preference, and a short-lived cache (30 minutes) of the latest GitHub release version and package sizes.

6. Data Control & Deletion

Because all data is stored locally, you have complete control over it at all times. You can delete individual hosts, credentials, AI conversations, or paired devices inside the app, restore earlier snapshots from Settings → About → Data folder, or completely remove all data by uninstalling Sshairy and clearing its local data folder and OS credential entries.

7. Open Source Verification & Contact

Sshairy is open-source under the MIT License; you can inspect the full source code at github.com/Marchen-orz/sshairy. If you have privacy questions or security concerns, please open an issue on GitHub Issues.
