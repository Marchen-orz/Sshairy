隐私政策

Sshairy 是一款本地优先、完全开源的 SSH 客户端。我们不设用户账号，不运营云同步服务器，也不集成任何统计埋点或广告 SDK。

最后更新：2026 年 11 月 27 日 · 适用于 Sshairy（Windows、macOS、Linux、Android）及官网 sshairy.marchen.top

零遥测追踪无使用统计、无崩溃自动上报、无广告 SDK，也没有开发者后端服务器。
系统安全存储密码、私钥与 API Key 仅存于操作系统安全存储，无明文降级。
通信完全可控所有网络请求仅发往你自行配置的服务器、模型端点或配对设备。

1. 我们不收集的数据

Sshairy 开发者不会收集、出售、出租或接收你的个人信息、SSH 主机配置、登录凭据、终端会话内容、传输文件或 AI 对话记录。使用 Sshairy 无需注册或登录任何账号，软件内不含任何第三方统计、遥测或广告组件。

2. 仅存于你本机的数据

  • 配置与工作区数据：主机、分组、身份元信息、已知主机信任记录（known hosts）、命令片段、端口转发规则、布局、设置以及本地快照均以 JSON 文件保存在操作系统的应用数据目录中。
  • 敏感凭据：SSH 密码、私钥、私钥口令、AI / 翻译 API Key 以及手机互联的 Ed25519 设备私钥种子仅保存在系统安全存储（Windows DPAPI、macOS 钥匙串、Linux Secret Service、Android Keystore）中。业务配置文件只保留不透明引用（SecretRef），绝不明文降级保存。
  • 外部 MCP 客户端访问令牌（按需开启）：仅当你在「设置 → MCP / Skill」中主动开启 Claude Code、Codex、Zcode、DeepSeek Harness 或 Antigravity 时，Sshairy 会向该客户端的本地用户配置文件写入一个可随时作废的本机回环访问令牌；关闭开关后即删除并作废该令牌。
  • 诊断与审计日志：有界、脱敏的诊断日志和 MCP 审计记录仅存于本地，不记录密码、私钥、原始请求头或敏感凭据，也不会自动上传。
  • 临时文件：外部编辑器的私有临时副本及断点续传产生的 .part 文件仅存于用户私有或目标目录，并在完成后清理。

3. 网络通信与第三方服务

Sshairy 仅在你主动配置或触发对应功能时发起网络请求：

  • SSH、SFTP 与端口转发：仅直连你配置的目标服务器、跳板机或代理；所有连接路径均在发送认证凭据前强制校验主机密钥。
  • Airy AI 功能（默认关闭）：在用户配置并启用自己的 Anthropic 或 OpenAI 兼容模型前，不会发起任何 AI 请求。启用后，仅在你主动提问、发起行内任务或触发 AI 补全时，将所需的有界上下文、经批准的工具结果或手动附加的文件/图片（图片会重编码以清除元数据）直接发往你指定的模型服务商。SSH 密码、私钥等秘密绝不会发给 AI。你发往模型服务商的数据受该服务商的隐私政策约束。
  • 在线补全说明翻译（可选）：启用后仅发送随软件打包的公开命令规格说明文本和目标语言，绝不发送你的命令历史、主机名、路径或文件名。如在 MyMemory 服务中自行填写了可选邮箱，该邮箱仅随 MyMemory 请求的 de 参数发送。
  • 手机互联（Device Link，默认关闭）：开启后仅在局域网或你指定的直连地址之间通过端到端加密（X25519 + Ed25519 + XSalsa20-Poly1305）通信，不经过开发者中转服务器。可选的局域网发现广播仅包含协议版本、设备 ID、设备名称与端口，不含任何主机列表或凭据；同步已保存的服务器密码需在电脑端显式弹窗确认。
  • 版本更新检查：客户端（及本官网）可能访问公开的 GitHub Releases API（api.github.com/repos/Marchen-orz/sshairy/releases/latest）检查新版本，并在你选择更新时从 GitHub 下载官方安装包。

4. Android 端权限说明

Sshairy Android 端遵循最小必要原则，仅在使用相关功能时按需申请权限：

  • 网络与震动：用于 SSH/SFTP/AI 连接、可选的局域网电脑发现以及触控板和审批触觉反馈。
  • 相机（可选）：仅在点击「扫一扫配对电脑」时申请，仅在本地实时识别二维码内容，绝不保存或上传影像。
  • 通知与前台服务（可选）：仅在你开启活跃会话后台保活或手机远程审批提醒时申请。
  • 生物识别（可选）：仅在你主动开启应用锁时调用系统生物识别验证；生物特征完全由 Android 系统处理，应用无法读取或存储。
  • 存储 / 所有文件访问权限（可选）：仅在你主动选择浏览本机完整目录或与电脑/服务器双向互传本地文件夹时引导授权；未授权时仍可使用系统文件选择器上传。
  • 绝不申请：Sshairy 绝不申请定位、通讯录、电话状态、短信或广告设备标识符权限。

5. 官网（sshairy.marchen.top）

本官网为纯静态页面，不使用 Cookie，无第三方统计与广告追踪脚本。仅在浏览器本地的 localStorage 中保存你的主题配色、深浅模式、语言偏好以及 GitHub 最新版本号与安装包体积的短期缓存（30 分钟），你可随时在浏览器中清除。

6. 数据控制与删除

由于全部数据均保存在你的本地设备上，你始终拥有完全控制权。你可以随时在应用内删除主机、凭据、AI 对话或已配对设备，在「设置 → 关于 → 数据目录」中管理或恢复本地快照，也可以通过卸载应用并清理本地数据目录与系统凭据条目来彻底删除所有数据。

7. 开源审计与联系方式

Sshairy 采用 MIT 许可证开源，所有数据与网络行为均可在 github.com/Marchen-orz/sshairy 公开查验。如有隐私或安全疑问，欢迎通过 GitHub Issues 联系我们。
